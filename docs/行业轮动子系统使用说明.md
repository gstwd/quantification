# 申万行业 RRG + 扩散轮动子系统使用说明

> 集成日期：2026-09-06。对应迁移 `0029_industry_rrg_subsystem`。

## 一、本子系统做了什么

在原有"宽基/指数策略系统"之外新增一套**隔离的申万一级行业研究子系统**：

- `industry_universe` / `industry_daily_bar`：31 个申万一级行业目录与官方行业指数日线（独立存储，不进 `benchmark_index`/`index_daily_bar`）；
- `industry_membership_event` / `stock_daily_close`：申万 2021 版成分事件与个股收盘（仅用于**数量占比扩散**，不做市值加权）；
- `industry_factor_value`：RRG（RS-Ratio / RS-Momentum / 象限）与扩散指标持久化；
- 策略引擎可选 `rotation` 模块：quadrant / diffusion / diffusion_rrg 三类研报信号，**不改变旧策略执行路径**；
- 标准回测（写统一 `backtest_*` 表，无费用无滑点、T 日收盘出信号、T+1 开盘成交、
  月末调仓，默认申万行业等权基准）；
- 数据研究调试页 `/tools/rrg-lab`（RRG 四象限/历史轨迹与数据覆盖、扩散时序/
  排名/覆盖度、数据问题显性化；仅做研究，不创建策略、不写因子、不触发回测）。

## 二、部署与初始化

```bash
cd apps/api
alembic upgrade head        # 应用 0029 迁移

# 1) 同步 31 个申万一级行业目录
python -m quant_etf_api.cli industry init-universe

# 2) 全量回填行业指数日线（申万官网，约 31 次请求）
python -m quant_etf_api.cli industry backfill-bars

# 3) 同步行业成分事件（申万分类历史，仅保留 2021 版体系回写后的事件）
python -m quant_etf_api.cli industry backfill-membership

# 4) 回填成分股历史收盘（baostock 默认自 2013-01-01，回退 AkShare）
python -m quant_etf_api.cli industry backfill-stock-close

# 5) 计算并持久化历史行业因子（可选；回测/调试 API 会即时计算，不依赖此步）
python -m quant_etf_api.cli industry compute-factors --start 2018-12-28 --end 2026-09-06
```

每日自动刷新默认开启：`industry_refresh_time=03:10` 触发
`industry_daily_ingest` → 完成后自动入队 `industry_factor_compute`；
可用环境变量 `QUANT_ETF_INDUSTRY_REFRESH_ENABLED=false` 关闭。

### 个股数据管理（迁移 0030）

`stock_universe` 存放个股目录与日线质量快照（对标 `benchmark_index`），
`stock_daily_close` 仅新增股票维度索引、列结构不变。前端页面：`/stocks`
（仅支持单股“质量检查/日线补全/全量重拉”，批量操作只在 CLI）：

```bash
alembic upgrade head        # 应用 0030 迁移
python -m quant_etf_api.cli stock init-universe   # 同步申万成分股元数据（名称/上市日/退市状态）
python -m quant_etf_api.cli stock quality --all   # 批量重算质量快照
python -m quant_etf_api.cli stock fill --all      # 批量补全到最近交易日
python -m quant_etf_api.cli stock fill --only-missing   # 只补缺失>0 或无数据的股票
python -m quant_etf_api.cli stock rebuild --codes 000009,600000   # 批量全量重拉（需指定代码）
```

质量口径：缺失数 = 期望区间（上市日→退市日/最近交易日）内交易日 - 实际行数，
停牌日会计入缺失且无法被补清；交易日历不可用时回退到行业日线交易日集合。

### 行业数据源管理（迁移 0031）

`industry_universe` 增加日线质量快照列（data_start/end_date、bar_count、
missing_day_count、quality_checked_at），前端页面：`/industries`（行业列表 +
“更新行业信息/增量刷新日线”全局按钮 + 行级“质量检查/日线补全/全量重拉”），
`/industries/:industryCode`（K 线 + 数据质量详情）。行业日线摄取链路统一补写
`prev_close_price/change_pct`（冲突行 DO UPDATE，历史存量经回填一次性补齐）：

```bash
alembic upgrade head        # 应用 0031 迁移
python -m quant_etf_api.cli industry backfill-bars      # 或 industry fill --all（顺带补写派生列）
python -m quant_etf_api.cli industry quality --all      # 批量重算行业质量快照
python -m quant_etf_api.cli industry fill --all         # 批量补全到最近交易日
python -m quant_etf_api.cli industry rebuild --codes 801010,801230   # 批量全量重拉（需指定代码）
```

行业日线缺失口径：以库内首根日线为期望起点、最近交易日为终点，按交易日历统计
中间缺口与尾部滞后；头部截断不计入，补全后仍可能因上游滞后残留尾部缺失。
总览页数据源状态与数据质量已接入行业日线/申万行业成分。

## 三、复刻策略与独立回测

```bash
# 创建复刻策略（扩散 top6 → 剔除三四象限 → 月末等权，默认 30 个行业）
python -m quant_etf_api.cli industry create-replica-strategy

# 标准回测（行业轮动走统一 backtest_* 表与标准绩效口径，默认行业等权基准；
# --daily 附逐日明细，--file 存 CSV）
python -m quant_etf_api.cli industry backtest \
  --start 2018-12-28 --end 2026-09-06 \
  --signal diffusion_rrg --top-n 6 --keep-quadrants 1,2 \
  --daily --file daily.csv

# 复刻策略同时可在策略中心“执行决策”，并在回测中心新建标准回测
```

`industry backtest` 内部创建临时标准策略并调用标准 BacktestService，不再维护
独立净值模拟（收益口径 T+1 开盘、月末调仓，基准默认行业等权剔除综合）。

## 四、调试页与只读 API

- 前端：`npm run dev` 后访问 `/tools/rrg-lab`（侧栏“因子中心 → RRG / 扩散研究”），
  该页为**数据研究版**：RRG 四象限散点/历史轨迹/日期选择与数据覆盖、扩散时序/
  最新排名/每日覆盖度，页面顶部展示数据问题与口径说明；页面不创建策略、不写因子、
  不触发回测，与策略中心和回测中心无关联。
- 后端只读端点：
  - `GET /api/industry/indexes`
  - `GET /api/industry/rrg?start=&end=&industry_codes=&lookback_ratio=&lookback_mom=&smooth_window=`
    → 返回 `points` + `meta`（issues/coverage/notes）；单次上限 3700 自然日。
  - `GET /api/industry/diffusion?start=&end=&diffusion_lookback=&smooth_window=&with_coverage=true`
    → 返回 `points`（可选逐日覆盖度）+ `meta`（规则/issues/覆盖汇总）；
    扩散按行业分批加载成员股收盘，单次上限 2200 自然日。
  - `GET /api/industry/rotation?start=&end=&signal=&top_n=&keep_quadrants=1,2&monthly=true`

接口均为即时计算（warm-up 数据自动前移取数），不写库；超限或数据缺失返回
带明确 message 的 422，不再静默返回空列表。

## 五、口径与已知边界

1. RRG 采用 JdK 比率法，中枢 100；默认 `lookback_ratio=220`、`lookback_mom=60`、`smooth_window=20`；warm-up：RS-Ratio 239 个交易日、RS-Momentum 318 个交易日。
2. 行业等权基准默认剔除综合（801230），可在 rotation 配置的 `benchmark_exclude` 调整。
3. 扩散仅数量占比版（`diffusion_count_ratio`），与研报市值加权版有口径差异。
4. 成分事件过滤规则：`start_date >= 2014-02-21` 且 `update_time >= 2021-07-01`，按现行一级前缀映射；**start_date 为生效日非公告日**，与研报同级 PIT 风险；少数无法映射的孤立事件会被跳过并在日志中计数。
5. 复刻策略与回测均直接作用于申万官方行业指数资产域；可交易域代理指数映射不在本子系统内（后续人工注册）。
6. RRG/扩散 4 因子已在 `factor_definition` 登记（行业域/面板/rotation_input，
   默认参数 220/60/20/220），行业轮动策略/回测已收敛到标准链路并写统一
   `backtest_*` 表；因子中心详情可查看预计算数据状态。
