## 1. 系统概述

### 1.1 系统定位

> **系统范围：本系统只研究 A 股指数（宽基/行业指数），不研究 ETF。**

A股指数量化研究系统是一个面向 **A 股指数** 的量化研究与策略回测平台，支持 **日频** 数据处理和策略执行。核心能力：

- **因子研究**：内置 7 个量化因子（量能、动量、波动率、估值），支持 IC 分析和因子相关性矩阵
- **策略构建**：通过 JSON 配置即可创建策略，无需编写代码，支持择时、评分、过滤、排名、组合、风控等完整管线
- **策略回测**：日频回测引擎，输出专业绩效指标（夏普/索提诺/卡玛比率、Alpha/Beta/信息比率 等）
- **资产配置**：完整的择时 → 评分 → 排名 → 仓位分配决策全流程

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| **指数池（Universe）** | 可研究指数的全量列表，包括代码、名称、类别等元数据 |
| **因子（Factor）** | 用于评估资产投资价值的量化指标，如 20 日动量、PE 分位等 |
| **策略（Strategy）** | 一组 JSON 配置，定义了如何从因子值计算出仓位分配的完整逻辑 |
| **信号（Signal）** | 策略对每个资产输出的评分等级：HIGH（推荐配置）、MID（可选配置）、LOW（暂不配置） |
| **回测（Backtest）** | 在历史数据上运行策略，验证策略的历史表现 |
| **Regime（市场状态）** | 择时模块将市场分为三种状态：进攻（offensive）、中性（neutral）、防守（defensive） |

### 1.3 策略执行管线

```
[可选] 择时 Timing → 评分 Score → [可选] 过滤 Filter → 排名 Rank → 组合 Portfolio → [可选] 风控 Risk → 输出
```

Portfolio 模块为必选项，输出持仓权重。无 Portfolio 的策略只能查看得分和排名，无法执行回测。



## 2. 页面功能说明

### 2.1 研究总览（仪表盘）

**路径**：`/`（首页）

**功能**：系统全局状态一览。

**显示内容**：

| 区域 | 内容 | 说明 |
|------|------|------|
| 统计卡片 | 指数总数、活跃策略数、最新交易日、数据频率 | 系统核心指标快照 |
| 关注策略 | 星标策略的最新信号与仓位 | 快速查看关注策略当前决策 |
| AI 舆情概览 | 当日市场综合研判与情绪摘要 | 由 AI 分析链路生成，无数据时隐藏 |
| 最近运行 | 最近的任务执行记录 | 显示 Run ID、类型、策略、交易日、状态、时间 |

**操作**：

- **数据管理**：页头“数据管理”按钮与侧栏入口均跳转数据管理页，可手动同步全部数据、检查全部质量，或针对单个数据集/对象补最新、修复缺口和全量重拉。
- **健康快照生成时机**：后端启动**不再**自动执行质量检查。健康快照只在①手动触发“检查 / 同步 / 修复 / 重拉”，或②数据摄取任务（每日 17:30 全局同步）执行完成后更新。首次部署或快照被清空时，页面会提示“尚未生成健康快照”，点击“检查全部质量”即可生成。
- **全量历史回填**：在数据管理页对目标指数/数据集执行“全量重拉”（需要确认令牌）。
- **数据质量看哪里**：仪表盘不再单独展示数据质量，质量结论统一以数据管理页的健康快照为准。

**数据质量状态说明**（与数据管理页、指数详情页同一口径，取自 `data_health_snapshot`）：

- **正常（healthy）**：已满足该数据集的时效与字段质量规则
- **需关注（warning）**：存在日期落后或连续性缺口，需人工确认
- **异常（error）**：无数据、字段非法或最近一次维护失败
- **尚未检查（unknown）**：从未执行过统一质量检查（首次部署时常见）
- **上游不支持（unsupported）**：上游明确不提供该对象（如部分指数没有估值覆盖）



### 2.2 指数数据

#### 指数列表页

**路径**：`/indexes`

**功能**：查看所有基准指数及其最新估值数据。

**显示列**：

| 列名 | 说明 |
|------|------|
| 指数代码 | 6 位数字代码（如 000300 = 沪深300） |
| 名称 | 指数中文名称 |
| 最新收盘 | 最新交易日收盘点位 |
| 涨跌幅 | 当日涨跌百分比 |
| PE(TTM) | 滚动市盈率 |
| PE分位 | 当前 PE 在历史数据中的百分位（0-100%） |
| PB | 市净率 |
| PB分位 | 当前 PB 在历史数据中的百分位（0-100%） |

**操作**：

- **添加指数**：输入指数代码，系统自动获取名称和数据
- **删除指数**：移除指数（不删除已有历史数据）
- **点击行**：进入指数详情页

**重要提示**：仅有沪深300（000300）、上证50（000016）、中证500（000905）支持 PE/PB 历史分位数据（来自 legulegu 估值源），其他指数（如科创50、创业板指）的估值分位可能为空。

#### 指数详情页

**路径**：`/indexes/:indexCode`

**功能**：查看单只指数的详细行情和估值历史。

**显示内容**：

- **数据质量**：该指数的健康快照（日线行情 / 估值两个数据集各自一行），展示健康状态、记录数、覆盖范围、缺口与字段异常数、最近检查时间与数据来源；口径与数据管理页完全一致（`data_health_snapshot`），缺口与异常需在数据管理页发起“检查 / 修复缺口”。尚无快照时提示先执行“检查全部质量”。
- **最新估值快照**：最新收盘、涨跌幅、PE(TTM) + 分位、PB + 分位、股息率
- **K 线图**：OHLC 蜡烛图 + 成交量，含数据缩放控件
- **PE / PB 历史分位图**：PE 分位和 PB 分位两条线，范围 0-100%
- **数据维护**：卡片底部按钮深链到数据管理页的该指数分区

#### 行业详情页

**路径**：`/industries/:industryCode`

**显示内容**：

- **数据质量**：该行业日线的健康快照（`industry_daily_bar` 数据集），展示健康状态、记录数、覆盖范围、缺口与字段异常数、最近检查时间与数据来源；口径与数据管理页完全一致（`data_health_snapshot`）。尚未检查时提示先执行“检查全部质量”。

- **K 线图**：行业指数日线走势
- **数据维护**：卡片底部按钮深链到数据管理页的该行业分区

### 2.4 宏观指标

**路径**：`/macro`

**功能**：查看关键宏观经济指标的历史走势。

**指标说明**：

| 指标 | 含义 | 解读 |
|------|------|------|
| **CPI** | 居民消费价格指数（同比 %） | 衡量通胀水平。温和上涨（2-3%）为健康，> 5% 为高通胀，< 0% 为通缩 |
| **PMI** | 制造业采购经理指数 | 以 50 为荣枯线。> 50 表示制造业扩张，< 50 表示收缩。是经济周期的先行指标 |
| **LPR 1Y** | 一年期贷款市场报价利率（%） | 短期贷款基准利率，影响企业流动性贷款成本 |
| **LPR 5Y** | 五年期贷款市场报价利率（%） | 中长期贷款基准利率，主要影响房贷成本 |

**图表特性**：

- PMI 图有红色虚线标注荣枯线（50），便于快速判断经济景气度
- LPR 图同时展示 1 年期和 5 年期两条线，可比较利差变化



### 2.5 因子分析

#### 因子列表页

**路径**：`/factors`

**功能**：查看所有已注册的量化因子，每个因子卡片显示：

- **模板 ID**：因子唯一标识（如 `return`、`volatility`）
- **名称**：中文名称（如"N 日累计收益率"）
- **分类**：量能/动量/波动率/估值/技术/宏观/价格/相对强度/宽度
- **可调参标记**：带参数模式的模板显示"可调参"与参数摘要
- **描述**：因子的文字说明
- **所需数据**：计算该因子需要的数据类型
- **状态**：启用/禁用

**操作**：

- **编辑**：修改因子的名称、描述、分类或启用状态
- **启用/禁用**：控制因子是否参与策略计算
- **查看详情**：进入因子详情页进行深度分析

#### 因子详情页

**路径**：`/factors/:factorId`

**功能**：因子的深度分析，包含 4 个 Tab。模板带参数时，页面顶部提供参数表单（取值与范围由后端 `parameter_schema` 决定），**所有 Tab 都按当前参数从原始数据现算**，切换参数即重新计算。

**Tab 1：横截面快照**

展示某一天所有指数在该因子上的值，按降序排列。每行显示：

- 排名、指数代码、指数名称、因子值
- 相对分布柱：显示该指数因子值在全量中的归一化位置

操作：可指定日期与模板参数查询。点击"时间序列"按钮可跳转查看该指数的历史走势。

**Tab 2：时间序列**

展示单个指数在指定日期范围内的因子值走势图。输入指数代码（如 `000300`）、日期范围与模板参数后，后端按当前参数逐日现算。

**Tab 3：IC 分析（Rank IC）**

衡量因子预测能力的核心分析工具。

> **横截面规模决定可信度**：IC 是在"当日有因子值的指数"之间做排序相关。A 股指数池很小（2020–2025 年只有 8 个指数，目前 30 个），指数越少相关系数取值粒度越粗（只有 3 个指数时只能取 ±1 / ±0.5）。因此**横截面少于 20 个指数的交易日不产出有效 IC**，会被排除并在页面上提示（提示中会给出该区间观测到的最大指数数量）。可用 `min_cross_section_n` 查询参数显式放宽，但不建议调到 5 以下。

| 指标 | 含义 | 判读标准 |
|------|------|---------|
| IC 均值 | Rank IC 平均值 | 需结合 t 统计量与横截面指数数量；绝对值大小本身不能说明因子有效 |
| IC 标准差 | IC 波动程度 | 越小越稳定；横截面指数越少，噪声导致的标准差天然越大 |
| IC_IR | IC 均值/标准差（**未年化**） | 衡量稳定性，不衡量显著性 |
| t 统计量 | IC_IR × √有效样本数 | **\|t\| > 2** 才认为 IC 均值显著非零 |
| IC>0 占比 | IC 为正的交易日比例 | > 50% 说明多数时候方向正确，接近 50% 近乎随机 |
| 横截面指数数 | 有效观测的平均横截面指数数量 | 越大越可靠；悬浮可见最小~最大 |
| 数据点 | 有效 IC 计算天数 | > 30 天才具统计意义；前瞻窗口重叠时页面同时给出折算后的"有效样本数" |

柱状图：绿色柱 = IC > 0（预测方向正确），红色柱 = IC < 0（方向相反）。悬浮可看到该日的横截面指数数量——柱子高但指数少时属于小样本噪声，不代表因子强。

前瞻窗口（`forward_days`）大于 1 时，相邻交易日的前瞻收益互相重叠，IC 标准差会被低估、IC_IR 会被高估。系统在汇总中返回 `effective_n`（= 有效天数 / forward_days）与 `overlap` 标记，t 统计量按 `effective_n` 计算。

**Tab 4：因子相关性矩阵**

展示同一天各因子之间的 Spearman 秩相关系数热力图。

- **每一对因子使用各自共同覆盖的指数**（不要求所有因子都有值的全局交集），因此不同格子的样本数可能不同；悬浮可看到该对实际使用的指数数量。
- 成对样本不足（默认 < 20）或因子值恒定导致相关未定义时，格子显示为空，表示"无法判断"，**不是**"不相关"。
- 绿色 = 正相关，红色 = 负相关，深色 = 接近 0
- |r| > 0.7：高度冗余，建议只保留一个（需该对样本数足够才有意义）
- |r| < 0.3：互补性好，适合组合使用
- 页面顶部会显示当日指数数量与每对样本数区间；若所有因子对样本都不足，会直接提示而不渲染热力图。



### 2.6 策略管理

#### 策略列表页

**路径**：`/strategies`

**功能**：查看和管理所有策略配置。

**显示内容**：策略卡片（策略 ID、名称、版本、频率、资产范围、状态）

**操作**：

- **新建策略**：打开策略配置编辑器
- **点击策略卡片**：进入策略详情

#### 策略创建/编辑

**功能**：通过可视化表单构建策略配置 JSON。策略配置包含 6 个模块：

**① 评分模块（必填）**

为每个资产计算综合得分（0-100）。

- **因子列表**：选择因子 → 设置权重（正=正向，负=反向）→ 选择变换函数
- **变换函数**：将原始因子值映射到得分空间
  - `无变换`：直接使用原始值
  - `反转百分位`：100 - 原始值（用于估值因子）
  - `动量得分`：收益率分段映射
  - `量能得分`：量比分段映射
  - `趋势得分`：MA 偏离度映射
  - `裁剪 0-100`：限制值在 0-100
- **缺失因子策略**：忽略（重新归一化）/ 按零处理 / 排除资产

**② 择时模块（可选）**基于市场估值/趋势/量能判断市场 regime，控制总仓位。

- 配置因子和阈值（进攻阈值默认 65，防守阈值默认 35）
- 综合得分 ≥ 进攻阈值 → 进攻 regime（高仓位）
- 综合得分 ≤ 防守阈值 → 防守 regime（低仓位）
- 介于之间 → 中性 regime（中仓位）

**③ 过滤模块（可选）**

按条件过滤资产。支持 7 种操作符（>、<、≥、≤、=、≠、between），多条规则可选择 AND（全部满足）或 OR（任一满足）。

**④ 排名模块**

对资产按得分排序。支持 Top N（取前 N 名）或 Bottom N（取后 N 名）。排序字段可选综合得分、动量排名或估值排名。

**⑤ 组合模块**

配置仓位分配方案。回测要求策略必须配置此模块。

- **等权分配**：入选资产权重相同
- **得分加权**：按得分比例分配权重
- **择时仓位控制**：进攻/中性/防守三种 regime 下的总仓位上限（默认 80%/50%/20%）

**⑥ 风控模块（可选）**

设置仓位约束：

- **单资产仓位上限**（默认 30%）：防止单一资产风险集中
- **组合总仓位上限**（默认 100%）：限制整体风险暴露
- **最低现金比例**（默认 0%）：强制保留现金缓冲

**⑦ 调仓模块（可选）**

两条腿同时生效：**选股腿**重建组合成分，**风险腿**只把现有成分等比缩放到择时目标总仓位。频率可选每日/每周/双周/每月；两腿日程一致时等价于单腿口径。

**⑧ 因子别名声明（factor_aliases）**

策略里的每个因子引用名都要能解析成"模板 + 参数"，解析规则是：

1. 引用名在 `factor_aliases` 中声明 → 用声明的模板与参数；
2. 否则引用名本身就是模板 ID → 用该模板的默认参数。

同一模板可以在一个策略里多次出现（例如 `return_5d` 与 `return_20d` 都用 `return` 模板，参数分别是 5 和 20）；同模板同参数只计算一次。别名只是策略语义，回测/信号报告里会同时展示别名、模板与规范化参数。

示例：

```json
"score": { "factors": { "short_mom": 0.3, "long_mom": 0.7 } },
"factor_aliases": {
  "short_mom": { "template_id": "return", "params": { "period": 5 } },
  "long_mom": { "template_id": "return", "params": { "period": 20 } }
}
```

**操作模式**：

- **表单模式**：通过可视化表单配置（推荐）
- **高级模式（JSON）**：直接编辑 JSON（适合高级用户）



### 2.7 策略执行

**路径**：`/strategies/:strategyId`（策略详情页）

**功能**：查看策略配置详情 → 运行策略 → 查看信号和资产配置结果。

**信号表格**：展示最近一次策略运行的信号，按得分降序排列。每行显示：

| 列 | 说明 |
|------|------|

**页面结构**：

| 区域 | 内容 |
|------|------|

**维护操作**：

- **检查**：只扫描并刷新健康快照，不改动数据本身；数据集级与分区级均可执行。
- **补最新**：补齐到目标日期；数据集/分区级会显式请求上游，全局“同步全部数据”按各数据集节流规则执行。
- **修复缺口**：先扫描完整缺口再做定向补数，不会由定时任务自动执行。
- **全量重拉**：抓取校验通过后替换现有数据（弹窗输入 `REBUILD:<数据集>:<分区或 ALL>` 令牌确认），耗时长，不作为常规刷新手段。

**说明**：

- 健康快照不会在后端启动时自动生成；首次部署或快照为空时页面提示“尚未生成健康快照”，点击“生成首次快照”即可。
- 任务结果以页头下方横幅反馈（成功/部分成功/失败数据集与新增、修复记录数），分区级问题可直接在表格中定位后处理。
- 深链 `?dataset=<数据集>&partition=<分区>` 可直接打开指定数据集与分区。

## 4. 策略配置参考

### 4.1 完整配置结构

```json
{
  "strategy_id": "策略唯一标识（英文，无空格）",
  "display_name": "策略中文名称",
  "version": "1.0.0",
  "description": "策略的详细描述",
  "frequency": "daily",
  "schema_version": "2",
  "index_codes": ["000300", "000905"],
  "factor_aliases": { "别名": { "template_id": "模板 ID", "params": { "period": 20 } } },
  "timing": { /* 择时配置，可选 */ },
  "score": { /* 评分配置，必填 */ },
  "filters": { /* 过滤配置，可选 */ },
  "rank": { /* 排名配置，必填 */ },
  "portfolio": { /* 组合配置，可选 */ },
  "risk": { /* 风控配置，可选 */ },
  "rebalance": { /* 调仓配置，可选 */ }
}
```

`factor_aliases` 是评分/择时/过滤/排名里因子引用的解析表：声明了别名就用别名指向的模板与参数，未声明的引用名按模板 ID + 默认参数解释。同一模板配不同参数必须通过别名区分，否则两个引用会解析成同一个实例。

### 4.2 各模块字段详解

#### 因子别名（factor_aliases，引用参数化模板时必填）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 别名 | str | — | 策略内唯一的引用名，评分/择时/过滤/排名用的就是它 |
| template_id | str | — | 因子模板 ID（`GET /api/factors/` 可查全部模板） |
| params | dict[str, number] | {} | 模板参数覆盖；未给的参数取模板默认值，未知参数或越界值在保存前被拒绝 |

#### 评分配置（score，必填）

#### 调仓配置（rebalance，可选）

启用本模块时**两条腿同时生效**，各自持有一份日程（`schedule`）：

- **选股腿 `selection`（必选）**：重建组合成分与权重；
- **风险腿 `risk`（必选）**：只把**现有成分**等比缩放到择时目标总仓位，不引入新成分。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| selection | object | `{"frequency": "daily"}` | 选股腿日程 |
| risk | object | 与 selection 相同 | 风险腿日程；JSON 中只给一条腿时，另一条腿自动按相同日程补齐 |
| selection.frequency / risk.frequency | str | "daily" | 调仓频率：daily/weekly/biweekly/monthly（其他取值会被配置校验直接拒绝） |
| selection.day_of_week / risk.day_of_week | int\|null | null | 周度/双周调仓日（0=周一, 4=周五），范围 0-4，默认 4（周五） |
| selection.week_parity / risk.week_parity | str\|null | null | 双周频率**必填**：`odd`（奇数周）或 `even`（偶数周），按 ISO 周序（第 1 周起算） |
| selection.day_of_month / risk.day_of_month | int\|null | null | 月度调仓日（1-31，建议 ≤28）；超出当月天数时按当月最后一日处理 |

> **旧配置升级**：`rebalance` 下直接写 `frequency` / `day_of_week` / `day_of_month`
> （改造前的平铺写法）会被自动升级为**两腿同频**，因此历史策略的回测口径不变。
> **两腿同频**（含旧配置升级后的形态）时，每个调仓日按"新成分 + 择时目标仓位"重建，
> 等价于改造前的单腿行为。
> **两腿异频**时：选股腿日只替换成分、维持当前总仓位；总仓位只在风险腿日按择时
> 目标调整。空仓时风险腿不会建仓（建仓由选股腿负责）。
> 未配置择时（timing）时，风险腿只会把仓位缩放到 `portfolio.default_exposure`
> （结构校验会给 warning）。
>
> **顺延语义**：调仓日 = 目标日（含）之后的第一个交易日。目标日休市时同周顺延
> （周三休市 → 周四）、跨周顺延（周五休市 → 下周一）、跨月顺延（1/28 休市 →
> 2 月首个交易日）都成立；同一自然周/周期/月内至多调仓一次。双周未命中的周期
> 即使目标日休市也不会在下一个周期补触发。
> 另：策略顶层的 `frequency` 只是**标注字段**，不控制调仓。

## 5. 回测结果解读指南

### 5.1 权益曲线

**含义**：策略净值（初始 = 0%）随时间的累积变化。叠加基准曲线可直观评估是否跑赢市场。

**判断标准**：
- 策略线在基准线上方 → 策略跑赢基准（有超额收益）
- 策略线走势平滑向上 → 策略稳健
- 策略线大幅波动 → 策略波动大，需关注回撤

### 5.2 回撤曲线

**含义**：策略净值从历史高点的回撤幅度（负数）。曲线越低表示亏损越大。

**判断标准**：
- 回撤在 -10% 以内 → 低风险策略
- 回撤在 -10% 到 -25% → 中等风险
- 回撤超过 -25% → 高风险策略
- 回撤恢复得快（曲线快速回到 0）→ 策略韧性好

### 5.3 仓位变化

**含义**：各指数持仓权重随时间的变化（堆叠面积图）。

**判断标准**：
- 权重切换平缓 → 换手率低，成本低
- 权重快速切换 → 换手率高，注意成本影响
- 现金比例大（灰色区域）→ 策略偏保守/防守

### 5.5 择时状态变化（配置模式）

**含义**：每一天的市场 regime（进攻=绿色 / 中性=黄色 / 防守=红色）时间线。

**判断标准**：
- 防守状态占比过高 → 策略过于保守，可能错失机会
- 进攻状态占比过高 → 策略过于激进，熊市可能大幅回撤
- 信号准确率高而防守多 → 择时有效，规避了下跌

### 5.6 绩效指标综合分析

| 如果... | 则... |
|---------|------|
| 夏普高 + 回撤低 | 策略风险收益比好 |
| 夏普高 + 回撤高 | 高收益但伴随高风险 |
| 夏普低 + 胜率高 + 盈亏比高 | 可能有异常值影响 |
| Alpha 显著 > 0 | 策略有独立于市场的超额收益能力 |
| Beta 接近 1 | 策略基本跟随市场 |
| 信息比率 > 0.5 | 主动管理能持续产生超额收益 |
| 换手率过高 | 实际执行时交易成本可能侵蚀收益 |



## 6. 常见问题

### Q1：为什么有些指数的 PE/PB 分位显示为空？

仅有沪深300（000300）、上证50（000016）、中证500（000905）支持 PE/PB 历史分位数据。其他指数（如科创50 000688、深证成指 399001、创业板指 399006）不返回估值分位，这是数据源（legulegu）的限制。此时页面会显示"—"。

### Q2：为什么回测详情页数据显示为"—"？

可能原因：

- 回测仍在执行中（状态为 pending/running），等待完成后自动刷新
- 基准对比未启用，所以基准相关指标为"—"
- 盈亏比为"—"：回测期间没有亏损日（极端情况）

### Q4：因子 IC 分析中 IC_IR 很低怎么办？

IC_IR = IC 均值 / IC 标准差（未年化）。低 IC_IR 可能原因：

1. **横截面太小（最常见）**：指数池只有少数几个时，IC 本身噪声极大，IC_IR 自然偏低。先看"横截面指数数"与"t 统计量"——如果 |t| < 2，说明观察到的 IC 与噪声无法区分，此时调整因子参数没有意义。
2. **IC 均值低**：因子本身预测力不足，尝试调整因子参数或更换因子
3. **IC 标准差大**：因子在某些时段有效、某些时段失效，考虑加入择时判断或与其他因子组合
4. **数据点太少**：小于 30 天时统计意义不足，延长回测时间范围

反向也要注意：IC_IR 高不等于因子可用。柱子很高的单日 IC 往往来自横截面只有三五个指数的交易日；系统已把这类观测排除，并在页面上给出提示。

### Q5：数据管理页面显示“关注”或“异常”怎么办？

- 先执行“检查全部质量”确认问题范围；再对目标数据集或对象执行“补最新”或“修复缺口”。
- “全量重拉”会在成功抓取并校验后替换旧数据，需要输入确认令牌；不要把它作为常规刷新手段。
- 系统每日北京时间 17:30 自动同步全部数据并在同步完成后刷新健康快照；启动后端不会自动检查，快照不会自行更新，中间缺口仅告警，不会自动修复。
- 页面显示“尚未生成健康快照”时，说明还没有任何检查记录：点击“检查全部质量”或等待下一次 17:30 全局同步即可。
- **点击"全量重拉"**：对目标指数/数据集重新抓取并替换历史数据（需确认令牌）
- 如果仍然过期/缺失：外部数据源（AkShare）可能不可用，等待稍后重试

### Q6：如何判断一个策略是否值得实盘？

综合考察以下维度：

| 维度 | 关键指标 | 合格线 |
|------|---------|--------|
| 收益 | 年化收益、累计收益 | > 基准收益 |
| 风险 | 最大回撤 | < 20% |
| 风险调整 | 夏普比率 | > 1.0 |
| 超额能力 | Alpha | > 0（且显著） |
| 稳定性 | 信息比率 | > 0.5 |
| 换手 | 换手率 | < 30%/日 |

### Q7：策略中变换函数怎么选？

| 因子类型 | 推荐变换函数 | 原因 |
|---------|------------|------|
| 收益率因子（return_*） | momentum_score | 将收益率分段映射为合理得分 |
| 估值因子（pe/pb_percentile） | invert_percentile | 低分位 = 便宜 = 高得分 |
| 量能因子（volume_ratio） | volume_score | 适中放量得分最高 |
| 波动率因子（volatility） | clamp_0_100 或用负权重 | 低波动 → 高得分 |
| MA 偏离因子 | trend_score | 价格相对均线的位置映射 |

### Q8：生命周期体检中的组合分数 IC 与单因子 IC 有什么区别？

生命周期页面用**组合分数 Rank IC**判断策略选优信号是否衰减：它只比较实际执行选股
调仓日的综合 `signal_score` 与其实际调仓周期后的指数收益。日/周/月策略的前瞻期分别为
1/5/21 个交易日（双周为 10 个交易日）。

横截面只包含**当天真正参与评分**的资产（通过候选池与过滤规则者），而不是当天
落库的全部标的：未参与评分的资产得分为占位 0，算进去会占据固定底部名次、把 IC
和 t 值都带偏。因此页面同时显示"评分 N / 标的 M"与评分覆盖率——覆盖率低不等于
指标有问题，它只说明当天有多少标的真的进了排序。

有效 IC 要求当天至少 5 个评分资产；单因子 IC 的 20 个门槛不适用于这里，因为
策略级横截面本来就是候选池，规模由策略标的范围决定。

单因子 IC 只用于诊断评分模块因子对组合变化的可能解释，不决定健康等级；过滤和
择时因子不应被当作单独的横截面 Alpha 因子。只有策略表现衰减与组合分数 IC 显著
衰减同时出现，体检才会把“观察”升级为 Alpha 衰减告警。注意单因子诊断取全交易日，
与只取选股调仓日的组合分数 IC 日期集不同，两者数值不可直接比较。

组合分数 IC 的观测数等于监控区间内的**选股调仓次数**：174 个交易日下日频约 173、
周频约 34、双周约 17、月频约 8。判定衰减需要至少 24 个观测（单因子诊断是 40 个），
系统会按实际交易日历核验相邻前瞻窗口是否重叠：完全不重叠才使用全部观测数；若月初/
月末或节假日顺延使窗口重叠，则保守折算有效样本数，避免高估 t 值。观测不够时页面显示
“调仓日观测不足，无法判断”，并给出还差几个调仓日、约需几个月，同时提示本次体检
未采用 IC 证据——**“未确认衰减”不等于“信号仍然有效”**，请勿据此判断策略健康。
