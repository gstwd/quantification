## 1. 系统概述

### 1.1 系统定位

量化 ETF 资产配置系统是一个面向 **A 股 ETF** 的量化研究与策略回测平台，支持 **日频** 数据处理和策略执行。核心能力：

- **因子研究**：内置 7 个量化因子（量能、动量、波动率、估值），支持 IC 分析和因子相关性矩阵
- **策略构建**：通过 JSON 配置即可创建策略，无需编写代码，支持择时、评分、过滤、排名、组合、风控等完整管线
- **策略回测**：日频回测引擎，输出专业绩效指标（夏普/索提诺/卡玛比率、Alpha/Beta/信息比率 等）
- **资产配置**：完整的择时 → 评分 → 排名 → 仓位分配决策全流程

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| **ETF 池（Universe）** | 可投资 ETF 的全量列表，包括名称、跟踪指数、类别等元数据 |
| **因子（Factor）** | 用于评估资产投资价值的量化指标，如 20 日动量、PE 分位等 |
| **策略（Strategy）** | 一组 JSON 配置，定义了如何从因子值计算出仓位分配的完整逻辑 |
| **信号（Signal）** | 策略对每个资产输出的评分等级：HIGH（推荐配置）、MID（可选配置）、LOW（暂不配置） |
| **回测（Backtest）** | 在历史数据上运行策略，验证策略的历史表现 |
| **Regime（市场状态）** | 择时模块将市场分为三种状态：进攻（offensive）、中性（neutral）、防守（defensive） |

### 1.3 策略执行管线

```
[可选] 择时 Timing → 评分 Score → [可选] 过滤 Filter → 排名 Rank → 组合 Portfolio → [可选] 风控 Risk → 输出
```

Portfolio 模块为必选项，输出持仓权重。无 Portfolio 的策略只能查看得分和排名，无法执行回测。



## 2. 页面功能说明

### 2.1 研究总览（仪表盘）

**路径**：`/`（首页）

**功能**：系统全局状态一览。

**显示内容**：

| 区域 | 内容 | 说明 |
|------|------|------|
| 统计卡片 | ETF 总数、活跃策略数、最新交易日、数据频率 | 系统核心指标快照 |
| 数据源状态 | 各数据表的记录数、最新日期、最近入库时间 | 包括 ETF 日线、份额、指数日线、指数估值 4 个数据源 |
| 数据质量 | 各组数据的时效性 | 标记过期/缺失的指数代码，红色/橙色表示需关注 |
| 最近运行 | 最近的任务执行记录 | 显示 Run ID、类型、策略、交易日、状态、时间 |

**操作**：

- **触发数据摄取**：手动触发增量数据拉取（从外部 API 获取最新交易日数据）
- **历史回补**：触发全量历史数据回填（适用于首次部署或数据缺失修复）

**数据质量状态说明**：

- **正常**：数据覆盖全部预期标的，且日期在 3 个日历日内
- **过期**：该标的最新数据日期超过 3 天（显示橙色）
- **缺失**：该标的完全没有数据（显示红色）



### 2.2 ETF 管理

#### ETF 列表页

**路径**：`/etfs`

**功能**：管理 ETF 投资池，查看所有已入库的 ETF。

**显示列**：代码、名称、交易所、跟踪指数、类别、状态

**操作**：

- **添加 ETF**：输入 6 位 ETF 代码，系统自动从数据源获取基金名称、跟踪指数、基金公司等信息
- **下架 ETF**：将 ETF 标记为不可交易（不删除历史数据）
- **点击行**：进入 ETF 详情页

#### ETF 详情页

**路径**：`/etfs/:etfCode`

**功能**：查看单只 ETF 的详细信息和历史行情。

**显示内容**：

- **基本信息**：名称、代码、交易所、类别、跟踪指数、基金公司、规模（亿元）、总份额（亿份）
- **K 线图**：OHLC 蜡烛图 + 成交量柱图，支持交互缩放和数据缩放
- **份额历史**：总份额随时间变化趋势线

**日期范围预设**：近 30 日 | 近 60 日 | 近半年 | 近 1 年 | 全部



### 2.3 指数数据

#### 指数列表页

**路径**：`/indexes`

**功能**：查看所有基准指数及其最新估值数据。

**显示列**：

| 列名 | 说明 |
|------|------|
| 指数代码 | 6 位数字代码（如 000300 = 沪深300） |
| 名称 | 指数中文名称 |
| 最新收盘 | 最新交易日收盘点位 |
| 涨跌幅 | 当日涨跌百分比 |
| PE(TTM) | 滚动市盈率 |
| PE分位 | 当前 PE 在历史数据中的百分位（0-100%） |
| PB | 市净率 |
| PB分位 | 当前 PB 在历史数据中的百分位（0-100%） |

**操作**：

- **添加指数**：输入指数代码，系统自动获取名称和数据
- **删除指数**：移除指数（不删除已有历史数据）
- **点击行**：进入指数详情页

**重要提示**：仅有沪深300（000300）、上证50（000016）、中证500（000905）支持 PE/PB 历史分位数据（来自 legulegu 估值源），其他指数（如科创50、创业板指）的估值分位可能为空。

#### 指数详情页

**路径**：`/indexes/:indexCode`

**功能**：查看单只指数的详细行情和估值历史。

**显示内容**：

- **最新估值快照**：最新收盘、涨跌幅、PE(TTM) + 分位、PB + 分位、股息率
- **K 线图**：OHLC 蜡烛图 + 成交量，含数据缩放控件
- **PE / PB 历史分位图**：PE 分位和 PB 分位两条线，范围 0-100%



### 2.4 宏观指标

**路径**：`/macro`

**功能**：查看关键宏观经济指标的历史走势。

**指标说明**：

| 指标 | 含义 | 解读 |
|------|------|------|
| **CPI** | 居民消费价格指数（同比 %） | 衡量通胀水平。温和上涨（2-3%）为健康，> 5% 为高通胀，< 0% 为通缩 |
| **PMI** | 制造业采购经理指数 | 以 50 为荣枯线。> 50 表示制造业扩张，< 50 表示收缩。是经济周期的先行指标 |
| **LPR 1Y** | 一年期贷款市场报价利率（%） | 短期贷款基准利率，影响企业流动性贷款成本 |
| **LPR 5Y** | 五年期贷款市场报价利率（%） | 中长期贷款基准利率，主要影响房贷成本 |

**图表特性**：

- PMI 图有红色虚线标注荣枯线（50），便于快速判断经济景气度
- LPR 图同时展示 1 年期和 5 年期两条线，可比较利差变化



### 2.5 因子分析

#### 因子列表页

**路径**：`/factors`

**功能**：查看所有已注册的量化因子，每个因子卡片显示：

- **factor_id**：因子唯一标识（如 `return_20d`）
- **名称**：中文名称（如"20日收益率"）
- **分类**：量能/动量/波动率/估值/份额流
- **描述**：因子的文字说明
- **所需数据**：计算该因子需要的数据类型
- **状态**：启用/禁用

**操作**：

- **编辑**：修改因子的名称、描述、分类或启用状态
- **启用/禁用**：控制因子是否参与策略计算
- **查看详情**：进入因子详情页进行深度分析

#### 因子详情页

**路径**：`/factors/:factorId`

**功能**：因子的深度分析，包含 4 个 Tab。

**Tab 1：横截面快照**

展示某一天所有指数在该因子上的值，按降序排列。每行显示：

- 排名、指数代码、指数名称、因子值
- 相对分布柱：显示该指数因子值在全量中的归一化位置

操作：可指定日期查询，也可强制重新计算。点击"时间序列"按钮可跳转查看该指数的历史走势。

**Tab 2：时间序列**

展示单个指数在指定日期范围内的因子值走势图。输入指数代码（如 `000300`）和日期范围后查询后端自动补算缺失日期的因子值。

**Tab 3：IC 分析（Rank IC）**

衡量因子预测能力的核心分析工具。

| 指标 | 含义 | 优秀标准 |
|------|------|---------|
| IC 均值 | Rank IC 平均值 | > 0.03（有正向预测力） |
| IC 标准差 | IC 波动程度 | 越小越稳定 |
| IC_IR | IC 均值/标准差 | > 0.5 较稳定，> 1.0 优秀 |
| IC>0 占比 | IC 为正的交易日比例 | > 50%，> 60% 较好 |
| 数据点 | 有效 IC 计算天数 | > 30 天才具统计意义 |

柱状图：绿色柱 = IC > 0（预测方向正确），红色柱 = IC < 0（方向相反）。柱子越高预测力越强。

**Tab 4：因子相关性矩阵**

展示同一天各因子之间的 Spearman 秩相关系数热力图。

- 绿色 = 正相关，红色 = 负相关，深色 = 接近 0
- |r| > 0.7：高度冗余，建议只保留一个
- |r| < 0.3：互补性好，适合组合使用



### 2.6 策略管理

#### 策略列表页

**路径**：`/strategies`

**功能**：查看和管理所有策略配置。

**显示内容**：策略卡片（策略 ID、名称、版本、频率、资产范围、状态）

**操作**：

- **新建策略**：打开策略配置编辑器
- **点击策略卡片**：进入策略详情

#### 策略创建/编辑

**功能**：通过可视化表单构建策略配置 JSON。策略配置包含 6 个模块：

**① 评分模块（必填）**

为每个资产计算综合得分（0-100）。

- **因子列表**：选择因子 → 设置权重（正=正向，负=反向）→ 选择变换函数
- **变换函数**：将原始因子值映射到得分空间
  - `无变换`：直接使用原始值
  - `反转百分位`：100 - 原始值（用于估值因子）
  - `动量得分`：收益率分段映射
  - `量能得分`：量比分段映射
  - `趋势得分`：MA 偏离度映射
  - `裁剪 0-100`：限制值在 0-100
- **缺失因子策略**：忽略（重新归一化）/ 按零处理 / 排除资产

**② 择时模块（可选）**

基于市场估值/趋势/量能判断市场 regime，控制总仓位。

- 配置因子和阈值（进攻阈值默认 65，防守阈值默认 35）
- 综合得分 ≥ 进攻阈值 → 进攻 regime（高仓位）
- 综合得分 ≤ 防守阈值 → 防守 regime（低仓位）
- 介于之间 → 中性 regime（中仓位）

**③ 过滤模块（可选）**

按条件过滤资产。支持 7 种操作符（>、<、≥、≤、=、≠、between），多条规则可选择 AND（全部满足）或 OR（任一满足）。

**④ 排名模块**

对资产按得分排序。支持 Top N（取前 N 名）或 Bottom N（取后 N 名）。排序字段可选综合得分、动量排名或估值排名。

**⑤ 组合模块**

配置仓位分配方案。回测要求策略必须配置此模块。

- **等权分配**：入选资产权重相同
- **得分加权**：按得分比例分配权重
- **择时仓位控制**：进攻/中性/防守三种 regime 下的总仓位上限（默认 80%/50%/20%）

**⑥ 风控模块（可选）**

设置仓位约束：

- **单资产仓位上限**（默认 30%）：防止单一资产风险集中
- **组合总仓位上限**（默认 100%）：限制整体风险暴露
- **最低现金比例**（默认 0%）：强制保留现金缓冲

**操作模式**：

- **表单模式**：通过可视化表单配置（推荐）
- **高级模式（JSON）**：直接编辑 JSON（适合高级用户）



### 2.7 策略执行

**路径**：`/strategies/:strategyId`（策略详情页）

**功能**：查看策略配置详情 → 运行策略 → 查看信号和资产配置结果。

**信号表格**：展示最近一次策略运行的信号，按得分降序排列。每行显示：

| 列 | 说明 |
|------|------|
| 排名 | 按得分从高到低排序 |
| 指数代码 | 6 位数字代码 |
| 信号得分 | 0-100，越高越值得配置 |
| 信号等级 | HIGH（推荐） / MID（可选） / LOW（暂不配置） |
| 择时状态 | 进攻/中性/防守（如有择时模块） |

**资产配置决策**（配置模式下显示）：

- **择时信号**：当前 regime 和确信度
- **资产排名**：动量排名和估值排名
- **配置方案**：每个入选资产的仓位权重

## 3. 指标参数速查表

### 3.1 回测绩效指标速查

| 指标 | 中文名 | 公式概要 | 优秀标准 | 关键页面 |
|------|--------|---------|---------|---------|
| cumulative_return_pct | 累计收益率 | ∏(1+r/100)-1 | 视市场环境 | 回测详情 |
| annualized_return_pct | 年化收益率 | (1+R)^(1/y)-1 | > 10% | 回测详情 |
| max_drawdown_pct | 最大回撤 | min(净值/峰值-1) | \|回撤\| < 15% | 回测详情 |
| max_drawdown_days | 回撤持续天数 | max(回撤开始→恢复) | 天数越短越好 | 回测详情 |
| sharpe_ratio | 夏普比率 | mean/std×√252 | > 1.0 良好, > 2.0 优秀 | 回测详情 |
| sortino_ratio | 索提诺比率 | mean/下行std×√252 | > 1.5 良好, > 2.5 优秀 | 回测详情 |
| calmar_ratio | 卡玛比率 | 年化收益/\|回撤\| | > 1.0 良好, > 2.0 优秀 | 回测详情 |
| win_rate_pct | 胜率 | 正收益日/总日 | > 50% | 回测详情 |
| signal_accuracy_pct | 信号准确率 | T+1正收益/总持仓 | > 55% | 回测详情 |
| profit_loss_ratio | 盈亏比 | avg盈利/|avg亏损| | > 1.5 良好 | 回测详情 |
| alpha | Alpha | 年化策略-β×年化基准 | > 5% 良好, > 10% 优秀 | 回测详情 |
| beta | Beta | Cov(P,B)/Var(B) | 1=同步市场, <1=防御型 | 回测详情 |

## 5. 回测结果解读指南

### 5.1 权益曲线

**含义**：策略净值（初始 = 0%）随时间的累积变化。叠加基准曲线可直观评估是否跑赢市场。

**判断标准**：
- 策略线在基准线上方 → 策略跑赢基准（有超额收益）
- 策略线走势平滑向上 → 策略稳健
- 策略线大幅波动 → 策略波动大，需关注回撤

### 5.2 回撤曲线

**含义**：策略净值从历史高点的回撤幅度（负数）。曲线越低表示亏损越大。

**判断标准**：
- 回撤在 -10% 以内 → 低风险策略
- 回撤在 -10% 到 -25% → 中等风险
- 回撤超过 -25% → 高风险策略
- 回撤恢复得快（曲线快速回到 0）→ 策略韧性好

### 5.3 仓位变化

**含义**：各指数持仓权重随时间的变化（堆叠面积图）。

**判断标准**：
- 权重切换平缓 → 换手率低，成本低
- 权重快速切换 → 换手率高，注意成本影响
- 现金比例大（灰色区域）→ 策略偏保守/防守

### 5.5 择时状态变化（配置模式）

**含义**：每一天的市场 regime（进攻=绿色 / 中性=黄色 / 防守=红色）时间线。

**判断标准**：
- 防守状态占比过高 → 策略过于保守，可能错失机会
- 进攻状态占比过高 → 策略过于激进，熊市可能大幅回撤
- 信号准确率高而防守多 → 择时有效，规避了下跌

### 5.6 绩效指标综合分析

| 如果... | 则... |
|---------|------|
| 夏普高 + 回撤低 | 策略风险收益比好 |
| 夏普高 + 回撤高 | 高收益但伴随高风险 |
| 夏普低 + 胜率高 + 盈亏比高 | 可能有异常值影响 |
| Alpha 显著 > 0 | 策略有独立于市场的超额收益能力 |
| Beta 接近 1 | 策略基本跟随市场 |
| 信息比率 > 0.5 | 主动管理能持续产生超额收益 |
| 换手率过高 | 实际执行时交易成本可能侵蚀收益 |



## 6. 常见问题

### Q1：为什么有些指数的 PE/PB 分位显示为空？

仅有沪深300（000300）、上证50（000016）、中证500（000905）支持 PE/PB 历史分位数据。其他指数（如科创50 000688、深证成指 399001、创业板指 399006）不返回估值分位，这是数据源（legulegu）的限制。此时页面会显示"—"。

### Q2：为什么回测详情页数据显示为"—"？

可能原因：

- 回测仍在执行中（状态为 pending/running），等待完成后自动刷新
- 基准对比未启用，所以基准相关指标为"—"
- 盈亏比为"—"：回测期间没有亏损日（极端情况）

### Q4：因子 IC 分析中 IC_IR 很低怎么办？

IC_IR = IC 均值 / IC 标准差。低 IC_IR 可能原因：

1. **IC 均值低**：因子本身预测力不足，尝试调整因子参数或更换因子
2. **IC 标准差大**：因子在某些时段有效、某些时段失效，考虑加入择时判断或与其他因子组合
3. **数据点太少**：小于 30 天时统计意义不足，延长回测时间范围

### Q5：数据质量页面显示"过期"或"缺失"怎么办？

- **点击"触发数据摄取"**：手动拉取最新交易日数据
- **点击"历史回补"**：全量回填历史数据
- 如果仍然过期/缺失：外部数据源（AkShare）可能不可用，等待稍后重试

### Q6：如何判断一个策略是否值得实盘？

综合考察以下维度：

| 维度 | 关键指标 | 合格线 |
|------|---------|--------|
| 收益 | 年化收益、累计收益 | > 基准收益 |
| 风险 | 最大回撤 | < 20% |
| 风险调整 | 夏普比率 | > 1.0 |
| 超额能力 | Alpha | > 0（且显著） |
| 稳定性 | 信息比率 | > 0.5 |
| 换手 | 换手率 | < 30%/日 |

### Q7：策略中变换函数怎么选？

| 因子类型 | 推荐变换函数 | 原因 |
|---------|------------|------|
| 收益率因子（return_*） | momentum_score | 将收益率分段映射为合理得分 |
| 估值因子（pe/pb_percentile） | invert_percentile | 低分位 = 便宜 = 高得分 |
| 量能因子（volume_ratio） | volume_score | 适中放量得分最高 |
| 波动率因子（volatility） | clamp_0_100 或用负权重 | 低波动 → 高得分 |
| MA 偏离因子 | trend_score | 价格相对均线的位置映射 |
