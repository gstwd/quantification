# A 股指数量化系统策略架构

本文档描述当前运行架构与口径；策略研究方法、参数高原和生命周期原则分别见链接文档，不在此重复定义。

## 边界与资产域

- 系统研究 A 股指数，频率为日频；不提供 ETF、个股交易或交易执行能力。
- 策略资产只能来自 `benchmark_index`，并且应有市场中实际 ETF 对应物。
- 申万行业和个股数据仅能作为 `rrg_industry_match_score`、`index_diffusion_ratio` 等指数级因子的内部输入；它们不能进入策略 `index_codes` 或作为回测标的。

## 执行管线

```text
StrategyEngine.run(config, context)
  → [可选] Timing
  → Score
  → [可选] Filter
  → Rank
  → [可选] Portfolio
  → [可选] Risk
  → EngineResult
```

`RebalanceScheduler` 在回测中决定何时实际重建成分和调整风险仓位；非执行日沿用已有持仓。策略配置必须包含 `portfolio` 才能创建回测。

| 组件 | 当前职责 |
| --- | --- |
| Timing | 根据市场级因子生成 offensive / neutral / defensive regime。 |
| Score | 按 `Σ(transform(value) × weight) / Σ(|weight|)` 评分，支持 absolute、rank、zscore。 |
| Filter | 支持 `gt/lt/gte/lte/eq/neq/between`、AND/OR 和跨因子比较。 |
| Rank | 按 score、momentum_rank 或 valuation_rank 排序并截取 TopN/BottomN。 |
| Portfolio | equal_weight、score_weight 或 winner_take_all；无择时时用 `default_exposure`。 |
| Risk | 限制单资产权重、总仓位和最低现金比例。 |

## 参数化因子现算

策略因子引用可以直接是模板 ID，也可在 `factor_aliases` 中声明别名、模板和参数：

```json
{
  "score": {"factors": {"short_mom": 0.3, "long_mom": 0.7}},
  "factor_aliases": {
    "short_mom": {"template_id": "return", "params": {"period": 5}},
    "long_mom": {"template_id": "return", "params": {"period": 20}}
  }
}
```

`FactorProvider` 收集引用并由 `FactorTemplateRegistry` 解析为规范化实例。实时分配通过 `load_asset_factor_matrix()` 和 `load_market_factors()` 从原始数据计算当前交易日；回测通过 `precompute_backtest_factors()` 使用预加载数据批量计算。`ContextBuilder` 只读地将这些结果组装为 `EngineContext`。

因子值不持久化，也没有因子值补算任务。`factor_definition` 保存的是模板目录；原始数据不足或计算失败会作为结构化缺失结果返回。详见[参数化因子与参数高原治理升级方案](参数化因子与参数高原治理升级方案.md)。

## 回测与可比性

`BacktestService` 在创建时快照策略配置和哈希，执行时优先使用快照。每个结果记录候选池、调仓日历来源、换手模型、数据质量口径、基准和执行模型。

- 研究期固定为 2016-01-01 至 2025-12-31；2026-01-01 起为验证期。
- `purpose=research` 不能越过研究期末端；validation/monitor 可用验证期，但会留下消费记录。
- 默认执行模型 `t_plus_1_open`，可选 `t_plus_1_close`；不同模型不可横向比较。
- 汇总收益是毛收益；详情页在读取时按换手率给出多档成本折算，不重跑历史回测。
- 交易日历不可用时拒绝给出近似结果，而不是退化为工作日历。

稳健性、优化与生命周期的规则见[策略稳健性评估与生命周期监控实施说明](策略稳健性评估与生命周期监控实施说明.md)。

## 扩展约定

1. 新因子以一个模板表示一套计算逻辑；周期、窗口等可调值写入 `parameter_schema`，不得新建带周期后缀的重复模板。
2. 新 transform 注册到 `engine/score.py` 的 `_TRANSFORM_REGISTRY`。
3. 新组合权重方法实现 `WeightAllocator` 并在 `engine/portfolio.py` 注册。
4. 新外部数据集必须走数据管理、健康快照和持久化队列，详见[数据管理与外部数据接入规范](数据管理与外部数据接入规范.md)。
