# 一、策略定位

## 目标

捕获沪深300指数：

- 熊市中的超跌反弹
- 牛市中的主升浪
- 牛市中的中继波段

同时规避：

- 长期熊市主跌段
- 牛市结束后的大回撤

------

## 核心思想

不预测市场。

只识别市场状态并进行应对。

```
市场状态
    ↓
策略模式
    ↓
仓位管理
    ↓
执行交易
```

------

# 二、策略框架

整个系统分为三层：

```
市场状态层
    ↓
波段交易层
    ↓
仓位控制层
```

------

# 第一层：市场状态识别

这是整个策略的核心。

先判断：

```
Bull
还是
Bear
```

然后再决定如何交易。

------

## 牛市状态

满足：

```
10月均线向上

AND

月线收盘价 > 10月均线
```

连续2个月成立。

------

定义：

```
Bull Market
```

特点：

- 上涨趋势已形成
- 中继调整大概率继续创新高
- 允许重仓持有

------

## 熊市状态

满足：

```
10月均线向下

AND

月线收盘价 < 10月均线
```

连续2个月成立。

------

定义：

```
Bear Market
```

特点：

- 下跌趋势占主导
- 反弹大于反转
- 优先保护资金

------

## 状态切换原则

允许滞后。

不追求最低点和最高点。

接受：

```
熊转牛
滞后10~20%

牛转熊
滞后10%左右
```

这是趋势系统的成本。

------

# 第二层：波段交易逻辑

牛市和熊市使用不同模式。

------

# 模式A：牛市趋势波段

## 牛市买点

目标：

```
寻找中继调整结束
```

而不是寻找大底。

------

满足：

### 条件1

出现回调：

```
距离近期高点回撤 >8%
```

------

### 条件2

重新站上5月均线

------

### 条件3

近2个月收益率重新转正

------

满足：

```
加仓
```

------

## 牛市卖点

目标：

```
确认趋势破坏
```

而不是预测顶部。

------

条件：

```
5月均线下穿10月均线
```

且：

```
3个月动量 < 0
```

------

执行：

```
减仓
```

------

如果：

```
10月均线开始走平
甚至转向下
```

进一步减仓。

------

### 牛市辅助风险信号

市场宽度恶化：

```
站上5月均线成分股比例
```

持续下降。

例如：

```
80%
↓
60%
↓
40%
```

而指数创新高。

------

属于顶部预警。

提前降低仓位。

------

# 模式B：熊市反弹波段

这是完全不同的逻辑。

------

## 熊市买点

目标：

```
超跌反弹
```

而不是趋势反转。

------

### 超跌条件

满足其一：

```
PE分位 < 20%
```

或者：

```
ERP > 80%历史分位
```

------

同时：

```
距离阶段高点跌幅 >15%
```

------

进入观察池。

------

### 反弹确认

满足：

```
连续2个月收阳
```

或者：

```
重新站上5月均线
```

------

执行：

```
试探建仓
```

------

## 熊市卖点

简单粗暴。

满足：

```
再次跌破5月均线
```

直接退出。

------

不幻想反转。

不长期持有。

------

# 第三层：仓位管理

估值不再决定是否交易。

只决定：

```
最大允许仓位
```

------

## 牛市仓位

| 状态     | 仓位 |
| -------- | ---- |
| 牛市启动 | 50%  |
| 趋势强化 | 80%  |
| 主升浪   | 100% |
| 宽度恶化 | 50%  |

------

## 熊市仓位

| 状态     | 仓位    |
| -------- | ------- |
| 普通熊市 | 0%      |
| 超跌观察 | 20%     |
| 反弹确认 | 30%-50% |
| 反弹失败 | 0%      |

------

原则：

```
牛市赚收益

熊市控回撤
```

------

# 四、因子体系

保留最有价值的几个因子。

------

## 状态因子

用于判断牛熊：

```
10MA方向
价格与10MA关系
```

------

## 趋势因子

用于波段：

```
5MA
10MA

3个月动量
6个月动量
```

------

## 估值因子

用于熊市超跌判断：

```
PE分位
PB分位
ERP分位
```

------

## 市场宽度因子

用于顶部风险监控：

```
沪深300成分股

站上5MA比例
```

------

# 五、策略运行流程

```
每月月底
    ↓
更新因子
    ↓
判断牛熊状态
    ↓

Bull ?
    ↓
是
    ↓

    ↓

    ↓

```

------

# 六、策略特点

## 优势

### 1. 符合沪深300历史特征

沪深300：

```
长期震荡向上
中间穿插大牛熊
```

非常适合：

```
趋势 + 估值
```

组合。

------

### 2. 不依赖预测

不猜：

```
最低点
最高点
```

只做确认。

------

### 3. 全周期覆盖

既能参与：

```
熊市反弹
```

又能参与：

```
牛市主升浪
```

------

### 4. 回撤控制能力强

长期熊市：

```
仓位自动下降
```

避免长期深套。

------

# 七、最终策略哲学

整个策略可以浓缩成一句话：

> **用长期趋势判断市场状态，用中期趋势捕捉波段机会，用估值寻找熊市机会，用市场宽度监控牛市风险。**

对于沪深300ETF而言，这比单纯的“低估值买入、高估值卖出”更完整，也比纯均线择时更符合A股牛熊切换和指数波动的真实特征。

如果未来要做实盘回测，我建议重点验证三个指标：

1. 牛熊状态识别（10MA模型）
2. 牛市中继加仓机制（回调+动量恢复）
3. 市场宽度顶部预警

这三个模块最终会决定这套策略长期收益和最大回撤的表现。
