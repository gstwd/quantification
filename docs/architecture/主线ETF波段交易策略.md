# 主线ETF波段交易策略

## 一、核心原则

### 原则1：不预测顶部，只响应顶部

错误思维：

```
已经涨很多了
应该快跌了
```

正确思维：

```
趋势破坏了
所以离场
```

我不猜测未来。

我只根据市场实际走势行动。

------

### 原则2：趋势优先于观点

即使我认为：

```
估值高
涨太快
要回调
```

只要：

```
趋势未破坏（价格 > MA20）
```

就不因为主观判断清仓。

市场永远比我的判断更重要。

------

### 原则3：主线优先

优先参与：

```
资金流入最多
上涨最强
趋势最完整
```

的板块。

而不是：

```
跌得最多
最便宜
```

的板块。

## 三、策略规则（量化版）

### 每日决策流程

```
Step 1: 计算动量得分
        score = return_20d × 0.7 + return_5d × 0.3

Step 2: 过滤
        条件A: close_price > ma_20d        （价格在20日均线上方，趋势完好）
        条件B: change_pct < 5              （不追单日暴涨超5%）
        条件C: max_drawdown_60d > -5       （60日峰值回撤不超5%，等效止损）

        三条必须同时满足（AND 逻辑）。
        不满足任一条件 → 该资产排除。

Step 3: 排序
        按动量得分降序排列。
        得分最高者为当前"主线"。

Step 4: 持仓
        如果至少1只资产通过过滤 → 满仓(100%)持有得分最高的资产
        如果0只资产通过过滤   → 空仓(0%)
```

### 规则详解

#### 买入条件（通过过滤 = 允许买入）

| 条件 | 规则 | 因子 | 目的 |
|---|---|---|---|
| 趋势完好 | `close_price > ma_20d` | close_price, ma_20d | 只在上升趋势中参与 |
| 不追涨 | `change_pct < 5` | change_pct | 避免FOMO追高买入 |
| 回撤可控 | `max_drawdown_60d > -5` | max_drawdown_60d | 等效止损，避开深度回调中的资产 |

#### 卖出条件

卖出不由单独的"卖出规则"触发，而是**通过过滤失败自然发生**：

| 触发场景 | 对应规则 | 含义 |
|---|---|---|
| 跌破 MA20 | 条件A 不满足 | **趋势破坏，离场** |
| 从近60日高点回撤超5% | 条件C 不满足 | **止损触发，离场** |
| 被另一资产动量反超 | 排名下降 | **主线切换，换仓** |

#### 等效止损机制

策略使用两层保护替代传统固定百分比止损：

- **第一层（主动）**：`max_drawdown_60d > -5` 从60日峰值回撤超5%立即退出，实现**峰值回撤止损**（trailing stop），比固定买入价止损更适应趋势行情
- **第二层（被动）**：MA20 跌破自动排除资产，在大多数情况下 5% 以上的单日跌幅会导致 MA20 被击穿

## 四、持仓管理

### 二进制仓位

简化加减仓操作为**空仓/满仓两种状态**：

- 有资产通过过滤 → 满仓持有动量得分最高者（100%）
- 无资产通过过滤 → 空仓（0%）

这避免了"减多少、何时加回"的主观判断，由过滤条件自动决定进出场时机。

### 主线切换

当之前持有的资产得分被另一个资产反超：

```
排名变化 → 换仓（卖旧买新）
```

这自然实现了持仓纪律中的"主线切换"逻辑。

### 全线走弱

当三只资产全部不满足过滤条件时：

```
自动空仓，等待下次机会
```

对应原文"趋势破坏 → 0%-30%仓位"的极端场景。

## 五、系统配置映射

以下是将策略规则映射到 `StrategyConfig` JSON 的完整配置：

```json
{
  "strategy_id": "mainline_momentum_rotation",
  "display_name": "主线ETF动量轮动",
  "version": "1.0.0",
  "description": "固定3只指数池，每日动量排名，MA20趋势过滤，赢家通吃满仓轮动。等效5%峰值回撤止损。",
  "frequency": "daily",
  "index_codes": ["000905", "399673", "931743"],
  "score": {
    "factors": {
      "return_20d": 0.7,
      "return_5d": 0.3
    },
    "scoring_mode": "absolute",
    "missing_factor_strategy": "exclude"
  },
  "filters": {
    "logic": "AND",
    "rules": [
      {
        "factor": "close_price",
        "op": "gt",
        "compare_to": "ma_20d"
      },
      {
        "factor": "change_pct",
        "op": "lt",
        "value": 5
      },
      {
        "factor": "max_drawdown_60d",
        "op": "gt",
        "value": -5
      }
    ]
  },
  "rank": {
    "sort_by": "score",
    "order": "desc",
    "top_n": 1
  },
  "portfolio": {
    "method": "winner_take_all",
    "default_exposure": 1.0
  },
  "rebalance": {
    "frequency": "daily"
  }
}
```

### 配置要点说明

| 配置项 | 取值 | 理由 |
|---|---|---|
| `index_codes` | `["000905","399673","931743"]` | 固定资产池，替代动态"主线识别" |
| `score.factors` | return_20d=0.7, return_5d=0.3 | 20日动量为主（趋势稳定性），5日动量为辅（近期强度） |
| `scoring_mode` | `absolute` | 每资产独立评分，3只小池无需横截面标准化 |
| `filters.rules[0]` | close_price > ma_20d | 趋势过滤核心：价格必须在均线上方 |
| `filters.rules[1]` | change_pct < 5 | 不追单日暴涨 |
| `filters.rules[2]` | max_drawdown_60d > -5 | 等效止损：峰值回撤超5%退出 |
| `rank.top_n` | 1 | 只持有得分最高的资产 |
| `portfolio.method` | winner_take_all | 赢家通吃，100%仓位集中于排名第一的资产 |
| `portfolio.default_exposure` | 1.0 | 满仓（通过过滤时） |
| `rebalance.frequency` | daily | 每日评估，及时响应趋势变化 |

### 涉及的现有因子

| 因子 ID | 类型 | 说明 |
|---|---|---|
| `return_20d` | momentum | 近20个交易日涨跌幅(%) |
| `return_5d` | momentum | 近5个交易日涨跌幅(%) |
| `close_price` | price | 当日收盘价 |
| `ma_20d` | technical | 20日简单移动均线 |
| `change_pct` | price | 当日涨跌幅(%) |
| `max_drawdown_60d` | technical | 当前价相对60日最高价的回撤幅度(%)，负数 |

全部 6 个因子均已内置，**不需要新增任何代码**。

## 六、策略优化说明

### 相比原始版本的简化

| 原始规则 | 简化处理 | 原因 |
|---|---|---|
| MA20 向上 | 删除 | MA20 位置已隐含趋势方向；均线上方运行时斜率通常为正 |
| 放量长阴退出 | 删除 | 系统无复合条件；长阴通常伴随 MA20 跌破，已被条件A覆盖 |
| 减仓（偏离MA20>15%、3天涨10%） | 删除 | 简化为二进制仓位；减仓后再加回的规则链在纯配置模式下难以表达 |
| 加仓方案A/B/C | 删除 | 回踩企稳/突破新高需要模式识别，超出配置表达能力 |
| 仓位三档（70-100%/50-80%/0-30%） | 简化为100%/0% | 二进制仓位更简洁，过滤条件自动决定进出 |
| 主观"主线"判断 | 量化为动量得分排名 | 20日+5日动量综合得分，客观可回测 |
| 主观"趋势破坏"判断 | 量化为 close < MA20 | 精确、无歧义 |
| 主观"止损5%" | 量化为 max_drawdown_60d > -5 | 峰值回撤止损，比固定买入价止损更适应趋势行情 |

### 简化后的策略本质

```
每日问一个问题：
  三只指数中，谁趋势最强且没有走坏？

有答案 → 满仓持有它
没答案 → 空仓等待
```

这就是"主线ETF波段交易"在系统约束下的最简洁表达。

## 七、风险提示与后续优化方向

### 当前局限性

1. **无择时模块**：策略不判断大盘整体环境（牛/熊/震荡），在系统性熊市中可能反复进出造成连续亏损。后续可考虑加入 `TimingConfig`，用沪深300的 MA20/MA60 作为市场环境过滤器。

2. **固定资产池风险**：3只指数的相关性较高（都是成长/中盘风格），在风格切换行情中可能同时走弱。后续可考虑加入低相关性的防守型资产（如红利指数）。

3. **回撤止损阈值需回测验证**：`max_drawdown_60d > -5` 中的 -5 是初始设定值，实际最优阈值（-3? -8? -10?）需通过历史回测确定。

4. **动量因子权重需回测验证**：`return_20d=0.7, return_5d=0.3` 的权重比例是初始设定，不同市场环境下最优权重可能不同。

5. **调仓频率**：每日调仓在趋势行情中表现良好，但在震荡市中可能产生过多无效换手。可考虑测试周度调仓（`frequency: "weekly"`）的效果。

### 后续可增强方向（需系统开发）

| 增强项 | 说明 | 优先级 |
|---|---|---|
| MA斜率因子 | 区分"均线上方盘整"和"均线上方上升"，减少假突破 | 低 |
| 复合条件过滤器 | 支持 `change_pct < -7 AND volume_ratio > 2` 等组合判断 | 中 |
| 止损模块 | 独立的止损管理，跟踪每笔交易的入场价和浮动盈亏 | 中 |
| 市场环境择时 | TimingConfig 加入大盘 MA20/MA60 判断，熊市自动降低仓位 | 高 |

## 八、回测验证建议

使用 `POST /api/backtests` 创建回测，关键参数建议：

- **日期范围**：至少覆盖 3 年以上（如 2023-01-01 至当前），包含一轮完整的牛熊周期
- **基准指数**：000300（沪深300），用于对比策略超额收益
- **关注指标**：
  - 年化收益率 vs 基准
  - 最大回撤（策略层面，非单资产）
  - 夏普比率
  - 胜率（持有期间正收益天数占比）
  - 换手率（日度调仓下的年化换手）
  - 空仓天数占比（反映策略的防御能力）

回测结果将客观揭示策略在历史行情中的表现，并帮助确定最优参数阈值。
