# 主线ETF波段交易策略

## 一、核心原则

### 原则1：不预测顶部，只响应顶部

错误思维：

```
已经涨很多了
应该快跌了
```

正确思维：

```
趋势破坏了
所以离场
```

我不猜测未来。

我只根据市场实际走势行动。

------

### 原则2：趋势优先于观点

即使我认为：

```
估值高
涨太快
要回调
```

只要：

```
趋势未破坏（价格 > MA20）
```

就不因为主观判断清仓。

市场永远比我的判断更重要。

------

### 原则3：主线优先

优先参与：

```
资金流入最多
上涨最强
趋势最完整
```

的板块。

而不是：

```
跌得最多
最便宜
```

的板块。

## 三、策略规则（量化版）

### 每日决策流程

```
Step 0: 大盘择时（月级别趋势判断）
        用沪深300的中周期因子判断市场月级别趋势：
          timing_score = momentum_score(return_60d) × 0.6
                       + drawdown_score(max_drawdown_60d) × 0.4

        两个因子各有分工：
        - return_60d：过去一个季度的涨跌幅，判断趋势方向（涨还是跌）
        - max_drawdown_60d：期间最大回撤，判断趋势质量（ smooth 还是颠簸）

        regime 判定：
          timing_score ≥ 65  → "进攻"（总仓位 80%）
          35 < timing_score < 65 → "观望"（总仓位 50%）
          timing_score ≤ 35  → "防守"（总仓位 20%）

Step 1: 计算动量得分
        score = return_20d × 0.7 + return_5d × 0.3
        使用 absolute 模式，保留原始动量幅度的差异。

Step 2: 过滤（AND 逻辑，全部满足才通过）
        条件A: close_price > ma_20d        （价格在20日均线上方，趋势完好）
        条件B: ma_5d > ma_20d              （短期均线在长期均线上方，均线多头排列）
        条件C: change_pct < 5              （不追单日暴涨超5%）
        条件D: max_drawdown_60d > -5       （60日峰值回撤不超5%，等效止损）

        不满足任一条件 → 该资产排除。

Step 3: 排序
        按动量得分降序排列。
        取前 2 名，等权配置。

Step 4: 持仓
        总仓位由 Step 0 择时决定，等权分配给通过过滤的前 2 名资产。
        如果 0 只资产通过过滤 → 空仓（0%），不受择时影响。
```

### 规则详解

#### 买入条件（通过过滤 = 允许买入）

| 条件 | 规则 | 因子 | 目的 |
|---|---|---|---|
| 趋势完好 | `close_price > ma_20d` | close_price, ma_20d | 只在上升趋势中参与 |
| 均线多头 | `ma_5d > ma_20d` | ma_5d, ma_20d | 短期均线在长期上方，确认均线多头排列，过滤"价格站上均线但均线走平"的假突破 |
| 不追涨 | `change_pct < 5` | change_pct | 避免FOMO追高买入 |
| 回撤可控 | `max_drawdown_60d > -5` | max_drawdown_60d | 等效止损，避开深度回调中的资产 |

#### 卖出条件

卖出不由单独的"卖出规则"触发，而是**通过过滤失败自然发生**：

| 触发场景 | 对应规则 | 含义 |
|---|---|---|
| 跌破 MA20 | 条件A 不满足 | **趋势破坏，离场** |
| MA5 下穿 MA20 | 条件B 不满足 | **短期动能衰减，离场** |
| 从近60日高点回撤超5% | 条件D 不满足 | **止损触发，离场** |
| 被另一资产动量反超 | 排名跌出前2 | **轮动换仓** |

#### 等效止损机制

策略使用两层保护替代传统固定百分比止损：

- **第一层（主动）**：`max_drawdown_60d > -5` 从60日峰值回撤超5%立即退出，实现**峰值回撤止损**（trailing stop），比固定买入价止损更适应趋势行情
- **第二层（被动）**：`ma_5d > ma_20d` 短期均线下穿长期均线时退出，比单纯的 MA20 跌破更早发出趋势转弱信号

## 四、持仓管理

### 择时驱动的动态仓位

策略通过沪深300中周期动量判断大盘**月级别趋势**，行情好时重仓、行情差时轻仓：

| regime | 触发条件（沪深300 月级别） | 总仓位 | 含义 |
|---|---|---|---|
| 进攻 | 60日涨幅 >5% 且回撤可控，择时得分 ≥65 | **80%** | 月级别上升趋势确立，积极进攻 |
| 观望 | 择时得分在 35-65 之间 | **50%** | 趋势方向不明或震荡，中等仓位 |
| 防守 | 60日跌幅 >5% 或回撤加深，择时得分 ≤35 | **20%** | 月级别下降趋势，轻仓防御 |

择时因子与评分因子**完全分离**：评分用短周期因子（return_20d/return_5d）选资产，择时用中周期因子（return_60d/max_drawdown_60d）判大盘——各司其职，互不干扰。

### 等权双持

在择时确定的总仓位下，等权持有动量得分前 2 名的资产：

- 有 ≥2 只通过过滤 → 等权分配总仓位（如进攻 80% → 各 40%）
- 有 1 只通过过滤 → 独享全部仓位
- 0 只通过过滤 → 空仓（即使择时允许高仓位，没有资产通过过滤也不强行买入）

### 主线切换

当排名前 2 的资产发生变化时：

```
排名变化 → 换仓（卖旧买新，维持等权配置）
```

等权模式下第 1 名和第 2 名互换位置不触发换仓——只有跌出前 2 名才会被替换，减少无效换手。

### 全线走弱

当三只资产全部不满足过滤条件时：

```
自动空仓，等待下次机会
```

择时模块可能在此时仍给出"进攻"信号（大盘没跌但成长风格熄火），但过滤层强制空仓，避免风格错配。

全部 8 个因子均已内置，**不需要新增任何代码**。

### 评分与择时因子分离设计

```
评分模块（选资产）              择时模块（判大盘）
─────────────────────────────────────────────────
return_20d (0.7)               return_60d (0.6)
return_5d  (0.3)               max_drawdown_60d (0.4)
↓                              ↓
短周期（1-4周）                 中周期（1-3月）
回答：哪只资产短期最强？         回答：大盘月级别趋势如何？
作用：排名选资产                 作用：决定总仓位（80%/50%/20%）
```

两组因子完全独立——评分继续用短周期抓波段轮动，择时用中周期判断月级别大方向。互不干扰，各司其职。

### 择时模块详解

#### momentum_score（趋势方向）

将涨跌幅（%）分段线性映射为 0-100 标准分：

| 沪深300 60日涨跌幅 | momentum_score | 趋势判断 |
|---|---|---|
| > 15% | 95 | 强牛市 |
| > 10% | 85 | 牛市 |
| > 5% | **70** | 稳步上涨 |
| > 2% | **60** | 温和上涨 |
| > 0% | 50 | 横盘偏多 |
| > -2% | 40 | 横盘偏空 |
| > -5% | **30** | 温和下跌 |
| > -10% | 20 | 明显下跌 |
| ≤ -10% | 10 | 大跌 |

#### drawdown_score（趋势质量）

将 60 日峰值回撤幅度（负数，如 -8.5 表示回撤 8.5%）映射为 0-100 标准分：

| 沪深300 60日最大回撤 | drawdown_score | 质量判断 |
|---|---|---|
| 0%（无回撤） | 100 | 趋势极 smooth |
| -5% | 80 | 轻微回调 |
| -10% | 60 | 正常调整 |
| -15% | 40 | 深度回调 |
| -20% | 20 | 接近转势 |
| ≤ -25% | 5 | 趋势破坏 |

#### 综合判定

```
timing_score = momentum_score(return_60d) × 0.6 + drawdown_score(max_drawdown_60d) × 0.4
```

return_60d 权重更高（0.6），因为趋势方向是主要矛盾；drawdown_score 占 0.4，用于辨别"稳步上涨"和"剧烈震荡中勉强收涨"——后者虽然 return_60d 可能为正，但高回撤意味着趋势脆弱，应降低仓位。

### v2.2 策略本质

```
每日问两个问题：
  1. 大盘月级别趋势如何？
     return_60d 判断方向（涨还是跌）+ max_drawdown_60d 判断质量（smooth还是颠簸）
     → 决定总仓位：进攻80% / 观望50% / 防守20%

  2. 三只成长指数中，哪两只短期趋势最强且没有走坏？
     return_20d + return_5d 排名 + MA20/MA5 过滤 + 止损
     → 决定买什么

行情好且趋势质量高（进攻）→ 80% 仓位
行情平或方向不明（观望）  → 50% 仓位
行情差或趋势颠簸（防守）  → 20% 仓位
没有资产通过过滤          → 空仓
```

短周期因子抓波段轮动，中周期因子判月级别大方向——两者因子完全分离，互不干扰。

## 七、风险提示与后续优化方向

### 当前策略定位

v2.2 是**阶段性战术策略**，针对月度量级波段行情的右侧交易。短周期因子选资产捕捉轮动，中周期因子判大盘趋势调节仓位——两组因子完全分离，各司其职。不作为全天候策略使用。

### 当前局限性

1. **择时与资产过滤可能冲突**：择时模块判断大盘为"进攻"（80% 仓位），但三只成长指数全部过滤失败 → 空仓。这本身是合理的设计（大盘涨但成长风格不在风口时不强行参与），但会导致择时信号与持仓脱节。

2. **资产池风格集中**：3只指数均为成长风格，相关性较高。择时用沪深300（大盘均衡），成长风格可能与大盘走势不同步——大盘进攻但成长走弱时，策略可能空仓或轻仓。

3. **参数需回测验证**：`max_drawdown_60d > -5` 的 -5 阈值、`return_20d=0.7, return_5d=0.3` 的权重比例、择时阈值 65/35 和权重 0.6/0.4 均为初始设定。实际最优值需通过历史回测确定。

4. **择时因子仅两个维度**：return_60d（方向）和 max_drawdown_60d（质量）覆盖了月级别趋势的核心特征，但缺少估值维度（如 erp_percentile）。如果市场在极度高估或低估状态，纯动量择时可能不够。当前行情下暂不需要，后续可加入。

### 当前行情下的策略适配性

| 市场特征 | 策略适配 |
|---|---|
| 月度量级波段轮动 | ✅ return_20d 为主（覆盖完整波段周期） |
| 右侧追趋势 | ✅ 均线多头 + 趋势过滤，只在趋势确认后参与 |
| 成长风格占优 | ✅ 3只成长指数池 |
| 月级别趋势判断 | ✅ return_60d + max_drawdown_60d 中周期择时，不因短期波动切换 regime |
| 行情好时重仓 | ✅ 择时进攻模式驱动 80% 仓位 |
| 行情差时轻仓 | ✅ 择时防守模式自动降至 20% |
| 趋势质量感知 | ✅ drawdown_score 区分 smooth 上涨和颠簸上涨 |

### 后续可增强方向

| 增强项 | 说明 | 优先级 |
|---|---|---|
| 回撤阈值调优 | 通过回测确定不同行情下 max_drawdown_60d 的最优阈值 | 高 |
| 动量权重调优 | 通过回测验证 return_20d/return_5d 和 return_60d/drawdown 的最优权重比 | 高 |
| 择时阈值调优 | 通过回测验证 offensive=65/defensive=35 的最优阈值 | 高 |
| 估值维度补充 | 择时加入 erp_percentile，在极端估值时调节仓位 | 中 |
| 量比确认 | 加入 `volume_ratio_20d` 过滤，排除缩量假突破 | 中 |
| regime_rules 条件化 | 不同 regime 下使用不同的过滤阈值（进攻放宽止损，防守收紧） | 中 |

## 八、回测验证建议

使用 `POST /api/backtests` 创建回测，策略 ID 使用 `mainline_momentum_rotation_v2`。

关键参数建议：

- **日期范围**：覆盖近期 1-2 年（如 2024-06-01 至当前），聚焦当前市场结构下的波段特征。如需验证参数稳健性，可扩展到 3 年以上
- **基准指数**：000300（沪深300），用于对比策略超额收益
- **关注指标**：
  - 年化收益率 vs 基准
  - 最大回撤（策略层面，非单资产）
  - 夏普比率
  - 胜率（持有期间正收益天数占比）
  - 换手率（日度调仓下的年化换手）
  - 空仓天数占比（反映策略的防御能力）

### 参数敏感性回测

建议针对以下参数做网格回测，找到当前行情下的最优值：

| 参数 | 测试范围 | 步长 |
|---|---|---|
| `max_drawdown_60d` 止损阈值 | -3 ~ -12 | 1 |
| `return_20d` 评分权重 | 0.5 ~ 0.9 | 0.1 |
| `timing.thresholds.offensive` | 55 ~ 75 | 5 |
| `timing.thresholds.defensive` | 25 ~ 45 | 5 |

回测结果将客观揭示策略在历史行情中的表现，并帮助确定最优参数阈值。
