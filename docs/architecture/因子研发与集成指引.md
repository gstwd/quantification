# 因子研发与集成指引

> 适用范围：本系统全部因子（指数因子、申万行业 RRG/扩散因子、未来基于机构
> 研报的新因子）。本文件是“先研究、再登记、后配置”流程的制度性说明。
>
> 资产边界：策略可配置资产只能是 `benchmark_index` 中用户自行添加、且
> 市场上存在实际 ETF 对应物的 A 股指数；行业与个股只作为因子输入，
> 不作为策略资产（申万 801xxx 永不进入策略/回测标的范围）。

## 一、两级体系：因子中心 vs 研究页

- **因子中心（正式因子）**：`factor_definition` 中 `is_active=true` 的因子，
  经过充分研究后可被策略配置引用、参与日频预计算与标准回测，是系统整个
  执行体系的正式组成部分。管理入口为前端“因子中心”与 `POST /factors/init`
  元数据同步。
- **研究页（独立实验）**：因子中心菜单下的研究页面（如“RRG / 扩散研究”）。
  用于按单篇研报/单条因子假设做独立实验：与正式系统只共享**只读数据**
  （行业日线、成分、个股收盘、指数行情等），逻辑完全独立——不创建策略、
  不写正式因子值表、不触发正式回测持久化，可携带自定义参数即时计算观察。
- **晋升门槛**：研究页结论达到以下条件后方可登记为正式因子：
  1. 口径定稿（复权/PIT/成分回写/缺数处理等已有明确文档说明）；
  2. 默认参数确定（参数化因子必须给默认参数与参数身份）；
  3. 预计算方案可行（实时读库、回测一次性预计算，不逐日全量扫描）；
  4. 回测口径通过验证（标准回测中心收益正确、有基准对照）；
  5. 可观测性达标（数据状态/缺口/warm-up 对前端可见）。

## 二、因子元数据三轴

每个因子必须显式声明以下三轴（`FactorSpec` / `factor_definition` 同步字段）：

| 轴 | 字段 | 取值 | 作用 |
| --- | --- | --- | --- |
| 语义族 | `category` | momentum/volume/volatility/valuation/technical/macro/price/relative_strength/breadth | 描述因子的数据刻画维度（展示/分组） |
| 值形态 | `value_shape` | asset / market | 决定加载与预计算方式：每资产值 / 市场级值。行业面板等只作因子内部数据依赖（required_data），不作为可配置因子 |
| 适用位置 | `usage` | timing / score / filter / rank | 决定因子能被策略管线哪些模块消费，配置校验与前端下拉按此过滤 |

参数化因子另需 `default_params` 与值表参数指纹（`params_hash`）：同一
factor_id 不同参数组合分行存储，正式消费者只读默认参数行（行业 RRG/扩散
已按此实现）。

## 三、开发流程（新增因子）

1. 在研究页先做数据研究：口径、覆盖、warm-up、与同类因子相关性/IC 评估；
2. 元数据登记：实现/声明 `FactorSpec` 三轴后运行 `init-factors`（或
   `POST /factors/init`）写入 `factor_definition`；
3. 接入计算与预计算：实时路径读预计算值表、回测路径一次性预计算面板，
   禁止逐日重算或研究页直接写正式值表；
4. 开放策略引用：配置校验按 usage 限制消费位置，前端表单同步
   该模块的因子下拉；
5. 标准回测验收：走回测中心，校验 T+1 口径、基准对照、缺口/预热告警。

## 四、行业 RRG / 扩散因子的定位

行业轮动已退化为“研究数据层 + 指数级因子输入”：

- 行业面板算法（RS-Ratio/RS-Momentum/象限/行业扩散）由 `domain/industry`
  纯函数与 `IndustryFactorService` 维护，研究工作台 `/industry/*` 继续
  按自定义参数即时计算，不创建策略、不写正式因子值表；
- 行业 4 因子不再登记为可配置正式因子（历史 `factor_definition` 行在
  同步后置 `is_active=False`），策略层不再存在 rotation 模块或行业资产域；
- 正式因子中心新增“指数级”因子：`rrg_industry_match_score`（内部先按
  研报信号对全部活跃申万一级行业做选择，再按指数成分股的申万行业暴露
  与选中行业集合计算重合匹配分）与 `index_diffusion_ratio`（指数成分股
  上涨占比），两者 `value_shape=asset`，可进
  score/filter/rank 并与其他因子自由组合；
- 指数成分数据优先接入免费源（baostock 对沪深300/中证500/上证50 提供
  按日期历史成分；AkShare csindex 提供当前成分与权重快照），历史 PIT
  覆盖不足的指数因子值从快照可用日起才有值；任意行业/主题指数严格
  历史 PIT 成分与权重需付费/积分数据源（Tushare Pro `index_weight` 或
  Wind/聚宽/米筐），本期不接付费源、数据层按 source/snapshot_type 预留。

## 五、其他约定

- 存量指数因子的 usage 默认放开（timing/score/filter/rank）；市场级因子
  （如 `breadth_ma20_pct`）按语义收敛为 timing/filter，不得放入 score/rank。
- 配置校验失败应在策略创建/编辑时即返回明确中文原因（含 usage），
  不允许“后端已支持某配置但前端无选项”或“前端可选但后端拒绝”的不一致。
