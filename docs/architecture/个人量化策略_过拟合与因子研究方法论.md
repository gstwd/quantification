*用于量化系统研究规范与 Codex 优化需求说明*

| **核心原则：量化研究无法消除未来不确定性；目标不是证明策略未来一定有效，而是降低历史拟合程度，提高策略规律延续到未来的概率。** |
|--------------------------------------------------------------------------------------------------------------------------------|

# 1. 文档目的

本文件用于指导个人量化系统的策略研究与系统优化，重点解决两个问题：一是如何正确理解并控制回测过拟合；二是个人量化在因子选择与参数优化上应采用怎样的复杂度。

- 建立“历史收益 ≠ 未来收益”的正确认知。

- 避免因大量参数搜索、因子堆叠和反复修改测试集导致隐性过拟合。

- 形成少量、逻辑清晰、参数稳定的因子研究流程。

- 让系统不仅输出“收益有多高”，还输出“这个收益有多可信”。

- 为 Codex 提供可落地的软件模块、指标与默认规则。

# 2. 如何理解量化回测中的过拟合

## 2.1 只要使用历史数据，就无法获得对未来的保证

任何策略都只能从过去的数据中学习或验证，而未来市场环境未知。因此，即使策略在所有历史时期都有效，也不能证明未来一定有效。金融市场还存在明显的非平稳性：参与者结构、交易制度、资金风格、估值水平和策略拥挤程度都会变化。

| **因此，“未来不确定”是不可消除的问题；“过拟合程度”则是可以管理的问题。** |
|--------------------------------------------------------------------------|

## 2.2 过拟合的本质

过拟合不是简单地指“策略使用了历史数据”，而是指策略过度利用了历史样本中的偶然噪声，并把这些噪声误认为稳定规律。

真实回测表现 ≈ 真实可持续规律 + 市场 Beta + 因子暴露 + 随机运气 +
数据挖掘/过拟合收益

研究的目标，是尽可能判断其中“真实可持续规律”的占比，而不是把历史回测收益最大化。

## 2.3 反复调试会让测试集失效

即使系统形式上划分了训练集和测试集，如果研究者看到测试集结果后继续修改参数、增加过滤条件或更换因子，那么测试集已经参与模型选择，不再是真正的样本外数据。研究者自身也是模型的一部分。

第一次：测试集表现差 → 修改参数  
第二次：仍然差 → 增加过滤条件  
第三次：测试集终于很好 → 保留  
  
结论：测试集已经被“间接训练”。

## 2.4 大量搜索会自然产生“历史冠军”

如果尝试成百上千个周期、阈值、因子组合和权重，即使所有策略都没有真实
Alpha，也可能随机产生几个非常漂亮的历史结果。因此，策略搜索空间越大，对最终历史最优结果越应保持怀疑。

# 3. 过拟合控制的正确目标

不应问“策略有没有过拟合”，因为几乎所有研究都会存在模型选择。更有意义的问题是：策略对历史数据细节的依赖程度有多高？

| **更可信的特征**            | **更危险的特征**         |
|-----------------------------|--------------------------|
| 逻辑简单、经济含义明确      | 规则复杂且很难解释       |
| 参数在较宽范围内都有效      | 只有某个精确参数异常优秀 |
| 跨时期有效                  | 收益集中在少数年份       |
| 不同市场/资产中具有相似规律 | 只在单一数据集有效       |
| 样本外仍有合理表现          | 样本外快速失效           |
| 成本提高后仍有优势          | 轻微增加成本即失效       |
| 少量核心自由度              | 大量参数、阈值和组合搜索 |

# 4. 因子策略的复杂度选择原则

## 4.1 个人量化优先“少量因子族”，不是盲目追求单因子

个人量化不必追求几十上百个因子。更推荐先围绕少数彼此逻辑不同的因子族建立模型，再判断它们是否互补。

| **因子族**             | **核心问题**             |
|------------------------|--------------------------|
| Momentum（动量）       | 最近谁更强？             |
| Quality（质量）        | 谁的盈利与财务质量更好？ |
| Value（价值）          | 谁更便宜？               |
| Size（规模）           | 谁规模更小？             |
| Low Volatility（低波） | 谁风险更低？             |
| Growth（成长）         | 谁的基本面改善更快？     |

建议一个个人多因子策略从 3～5 个核心因子族开始，每个因子族使用 1～3
个原始指标即可。总原始指标通常控制在约 5～10
个，比大量高度相关指标更容易获得稳定性。

## 4.2 区分“有意义的复杂性”和“拟合式复杂性”

- 合理复杂性：为了更完整表达一个经济概念。例如 Quality 由
  ROE、现金流质量、盈利稳定性、杠杆共同描述。

- 危险复杂性：为了追求历史收益不断加入精确阈值，例如 ROE \> 12.7%、PE \<
  28.3、MA37 \> MA83 等。

## 4.3 优先使用 Rank，而不是大量精确阈值

横截面排名能够减少对绝对阈值的依赖，并适应市场估值与波动环境变化。例如优先使用“估值最便宜的
20%”而不是“PE \< 24.6”。

示例：  
Momentum Rank + Quality Rank + Value Rank + Size Rank → 综合 Rank → Top
N

## 4.4 权重默认从等权开始

如果多个因子确实有效，其作用不应依赖非常精确的权重。默认采用等权或粗粒度权重，例如
1:1:1:1、2:2:1:1。对于 0.173、0.312
这类由历史优化得到的精确权重，应高度警惕。

# 5. 参数优化的推荐方法

## 5.1 不寻找单一历史最优点，而寻找“参数高原”

真正稳健的策略通常在一片参数区域内表现都合理。系统应优先寻找宽阔、平滑的稳定区域，而不是最大
Sharpe 的单个格点。

理想：40日、60日、80日、100日动量都有效  
危险：只有63日异常优秀，62日和64日明显失效

## 5.2 可以故意不用历史最优参数

如果一片参数区域都表现良好，应优先选择区域中央、具有自然时间含义或更容易解释的参数，而不是收益最高的精确参数。优化目标应从“最大化历史收益”改为“最大化未来风险调整收益的可信度”。

## 5.3 参数搜索使用粗粒度网格

- 周期优先测试 20/40/60/90/120 等粗粒度值，而不是 20～120
  每个整数全部扫描。

- 阈值优先使用分位数：Top 10%、20%、30%，避免 17.3%、22.6% 等精确阈值。

- 持仓数优先测试 Top 5/10/15/20/30/50。

- 调仓周期优先测试日/周/双周/月等具有明确业务含义的频率。

# 6. 因子增加与删除的研究流程

## 6.1 从最简单基准开始

Momentum  
↓  
Momentum + Quality  
↓  
Momentum + Quality + Size  
↓  
Momentum + Quality + Size + Value

每增加一个因子，都要求它在多个维度稳定改善结果，而不是只提高某段历史的
CAGR。

## 6.2 使用“删因子实验”验证贡献

对完整模型分别删除每一个因子，观察收益、回撤、Sharpe、换手率和稳定性的变化。若删除某因子几乎没有影响，则该因子应考虑移除。

| **模型** | **CAGR** | **MaxDD** | **Sharpe** |
|----------|----------|-----------|------------|
| M+Q+V+S  | 17.2%    | -18%      | 1.05       |
| Q+V+S    | 13.1%    | -20%      | 0.78       |
| M+V+S    | 14.0%    | -25%      | 0.74       |
| M+Q+S    | 16.4%    | -19%      | 1.00       |
| M+Q+V    | 15.7%    | -17%      | 1.02       |

## 6.3 复杂度必须证明自己的价值

任何新增因子、过滤条件或模型复杂度，都应与更简单版本直接对比。如果复杂度只带来极小的历史
Sharpe
改善，却大幅增加参数自由度、换手率或解释难度，应优先保留简单模型。

# 7. 稳健性与样本外验证框架

1.  时间分段：分别观察不同年份、牛市、熊市、震荡市。

2.  样本内/样本外：开发期与保留期严格分离。

3.  Walk Forward：滚动使用过去数据确定参数，并在下一阶段验证。

4.  参数敏感性：检查附近参数是否保持同方向效果。

5.  成本压力测试：手续费、滑点按 1x / 2x / 3x 测试。

6.  持仓数量敏感性：Top 5 / 10 / 15 / 20 / 30 / 50。

7.  基准与因子归因：拆分市场 Beta、Size、Value、Momentum 等暴露。

8.  实盘/纸面样本外：策略冻结后记录真实未知数据表现。

## 7.1 注意：真正的样本外会被“看结果后改策略”污染

系统应记录策略版本、参数版本与研究日期。若研究者查看样本外结果后修改策略，则应将该阶段标记为已使用数据，后续重新划分新的未知区间。

# 8. 建议新增到量化系统的“策略可信度评价模块”

Codex 优化系统时，建议将策略评价从单纯的收益/回撤报表升级为“收益表现 +
稳健性 + 复杂度 + 样本外可信度”的综合框架。

**A.
基础绩效指标**：CAGR、累计收益、年化波动率、最大回撤、Sharpe、Sortino、Calmar、胜率、盈亏比、回撤持续时间。

**B. 滚动表现**：滚动 3/6/12/24
个月收益、Sharpe、最大回撤；展示策略是否只依赖某一时期。

**C.
参数稳定性**：单参数曲线与双参数热力图；标记稳定高原而不是仅标记最优点。

**D. 样本内/样本外**：同一报表同时展示 IS 与 OOS
指标、差异比例和性能衰减。

**E. Walk Forward**：支持滚动训练/验证窗口，并汇总每个验证区间结果。

**F. 交易成本压力测试**：按手续费与滑点 1x/2x/3x 自动重算绩效。

**G. 持仓数敏感性**：自动测试 Top N
系列，并比较收益、回撤、换手、集中度。

**H. 因子消融**：自动运行 Full Model 与
Remove-One-Factor，评估每个因子的边际贡献。

**I. 因子相关性**：输出因子 Rank IC 相关性/信号相关性，识别重复因子。

**J.
策略版本记录**：保存策略逻辑、参数、数据截止日期、研究日期，防止测试集被反复使用而不自知。

# 9. 推荐的默认研究约束（可直接交给 Codex 实现）

- 默认不以“历史 Sharpe 最大”作为唯一参数选择标准。

- 参数优化结果必须同时输出最优值及其邻域表现。

- 若最优点周围性能急剧下降，标记为“参数脆弱”。

- 默认优先使用 Rank/分位数而不是精确绝对阈值。

- 多因子权重默认等权；只有在样本外持续改善时才允许复杂权重。

- 新增因子必须与简单模型做增量对比，并执行 Remove-One-Factor 消融。

- 若新增复杂度只带来微小历史提升，应在报告中给出“简化优先”提示。

- 所有回测必须支持真实手续费、滑点、涨跌停/停牌/无法成交约束。

- 策略必须记录数据截止日期，避免对“样本外”区间反复调参。

- 策略报告必须突出稳定性，而不是只突出历史最高 CAGR。

股票池  
↓  
排除 ST / 极端流动性 / 上市时间过短  
↓  
Size（可选：利用小资金容量优势）  
Quality  
Momentum  
Value  
↓  
各因子标准化或横截面 Rank  
↓  
默认等权合成综合 Rank  
↓  
Top 5 / 10 / 15 / 20 / 30 敏感性测试  
↓  
选择“稳定区域”而非历史最佳 N  
↓

该模板的重点不是追求最高历史收益，而是形成一个足够简单、能解释、能验证、可重复、方便后续迭代的研究基线。

# 11. 策略淘汰与降权原则

策略不是一次验证后永久有效。系统应支持持续监控，并把“失效”视为正常现象。建议关注：

- 滚动收益长期显著低于历史合理区间。

- 回撤显著超过历史压力测试范围。

- 因子 Rank IC 或信号预测能力持续接近零或反向。

- 交易成本、拥挤度或市场结构发生变化，使原逻辑不再成立。

- 实盘表现与回测差异持续扩大，而无法由成本和随机波动解释。

触发上述信号时，应优先采取降权、暂停、重新研究，而不是立即调参让历史曲线重新变漂亮。

对于个人量化，简单并不等于低级。金融数据的信噪比低、环境变化快，模型能够表达核心规律即可。复杂度只有在能够通过样本外、参数稳定性、成本压力与因子消融等检验后，才值得保留。

因此建议系统长期遵循：

简单基准 → 单因子验证 → 少量互补因子 → 粗粒度参数 → 稳健性检验 → 样本外
→ 实盘 → 持续监控  
  
而不是：  
大量因子 → 大量参数 → 历史最优组合 → 漂亮回测 → 直接实盘
