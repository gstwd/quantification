# 反过拟合纪律（配置策略时必须遵守）

来源：`docs/architecture/个人量化策略_过拟合与因子研究方法论.md`。
本文件把该文档中可执行的约束整理成配置阶段就能检查的清单。

## 1. 复杂度上限

| 项目 | 上限 | 说明 |
| --- | --- | --- |
| 因子族数量 | ≤ 5 | 逻辑彼此不同的族（动量/趋势/估值/低波/量能），同族内 1-3 个原始指标 |
| 原始指标总数 | ≤ 10 | 高度相关的指标堆叠会放大拟合空间但不增加信息 |
| 评分权重 | 默认等权 | 使用 1.0 / 0.5 这类粗粒度值；禁止 0.173、0.312 这类由历史最优得到的精确值 |
| 过滤条件数量 | ≤ 3 | 每多一个条件就多一次隐性的参数选择 |
| 阈值形式 | 优先分位数 | 用"估值最低 20%"而不是"PE < 24.6"；横截面排名比绝对阈值稳健 |

## 2. 参数粗粒度

- 周期类参数优先取 20 / 40 / 60 / 90 / 120 等档位，不做逐整数扫描。
- 持仓数优先取 3 / 5 / 10 等业务含义清晰的档位。
- 调仓周期优先取日 / 周 / 双周 / 月；**调仓星期（`rebalance.day_of_week`）属于
  无经济含义的旋钮**，不要为了让某段历史更好看而选择特定星期，也不要把
  回测最优的星期当作结论。

## 3. 资产池纪律

- 逐资产说明入选理由（宽基/风格/主题，为什么需要它），不要"看着历史挑了 21 个指数"。
- 检查每个资产是否有对应的可交易 ETF，以及研究期内是否有足够长的行情历史；
  后上市的指数会引入"事后才知道它存在"的选择性偏差。
- 记住：固定切分研究期/验证期能防参数过拟合，但**防不住资产池的事后挑选**；
  池子的选择偏差只能靠"当时可获得"的资产清单（PIT）来排除。

## 4. 创建后的必做动作

策略创建不等于研究完成，必须补齐：

1. 研究期基线回测（2016-01-01 ~ 2025-12-31），确认能跑通且不是空仓；
2. `robustness scan`（单旋钮邻域）：确认处于参数平台而不是尖峰；
3. 需要时 `robustness ablate`（删因子）：确认每个因子都有边际贡献，
   删掉几乎没有影响的因子；
4. 报告里写出**本次配置引用了几个因子族、几个可调参数、几个阈值**——
   这些数字是后续 Deflated Sharpe 的试验次数口径来源。

## 5. 禁止事项

- 不用验证期（2026-01-01 之后）数据来判断策略好坏；研究类回测会被系统直接拒绝。
- 不因"最近一年某参数回测更好"而修改已上线的策略（上线后配置已冻结）。
- 不为追求历史收益不断叠加过滤条件；新增复杂度必须能与更简单的版本对比。
