# 变换函数目录

评分计算时，可对原始因子值应用变换函数，将不同量纲的因子值映射到 0-100 的统一得分空间。

## 内置变换函数

| 变换名 | 函数 | 映射逻辑 | 适用场景 |
|--------|------|----------|----------|
| `invert_percentile` | 100 - value | 百分位反转，越低（越便宜）→ 得分越高 | 估值百分位因子 |
| `momentum_score` | 分段线性 | >15%→95, >10%→85, >5%→70, >2%→60, >0%→50, >-2%→40, >-5%→30, >-10%→20, ≤-10%→10 | 收益率/动量因子 |
| `volume_score` | 分段映射 | <0.3→10, <0.5→20, <0.8→35, <1.0→50, <1.3→70, <1.5→80, <2.0→85, <3.0→70, ≥3.0→50 | 量比因子 |
| `trend_score` | 线性 50+dev×5 | (price-ma60)/ma60×100 的偏离度线性映射，-10%→0, 0%→50, +10%→100 | 价格相对均线偏离 |
| `clamp_0_100` | max(0,min(100,v)) | 通用裁剪到 [0, 100] | 任意因子值 |
| `erp_score` | 分段线性 | >5→95, >3→80, >2→65, >1→50, >0→35, ≤0→15 | ERP 估值因子 |
| `drawdown_score` | 分段线性 | 0→100, -5→80, -10→60, -15→40, -20→20, ≤-25→5 | 回撤幅度因子（值为负） |
| `rsrs_score` | 线性裁剪 | z ≤ -2→0, z ≥ +2→100, 中间 50+z×25 | **`rsrs` 放 timing 时必须使用**，否则 ±3 量级的 z 值混入 0-100 空间几乎不影响合成得分 |

## 使用方式

在 `ScoreConfig.transforms` 中指定：

```json
{
  "score": {
    "factors": {"return_20d": 1.0, "pe_percentile": -0.5},
    "transforms": {
      "return_20d": "momentum_score",
      "pe_percentile": "invert_percentile"
    }
  }
}
```

- 未指定 transform 的因子直接使用原始值参与加权
- 使用不存在的 transform 名称会抛出 KeyError
